# 19금 글 계약

19금 글(`posts.adult`)은 **본인인증으로 만 19세 이상이 확인된 회원**에게만 보인다. 판정은 서버가 하고, 성인이 아니면 목록에서 아예 빠지고 글 보기·댓글은 403 이다.
게시판 말머리에 「성인 전용」을 두어, 그 말머리를 고른 글은 서버가 19금으로 저장한다(영상·짤 게시판의 「전방·후방」).

## 결정 (사용자, 2026-11-06)
1. **성인 = 로그인 + 본인인증 완료 + 만 19세 이상**(`IdentityVerificationService#isAdult` — 본인인증 생년월일 · `AdultAge`, 서비스 날짜 기준이라 19세 생일이 지나면 다시 인증하지 않아도 된다). 비회원·미인증·미성년은 성인이 아니다.
2. **성인이 아니면 목록에서 아예 숨김**(서버 질의에서 뺀다 — 쪽 수·건수도 뺀 기준): 게시판 목록·고정 공지·게시판 안 검색, 이전·다음 글, 최신글 전체, 통합 검색, 홈·가젯 페이지·게시판 레이아웃의 글 목록 가젯(최신글·게시판 카드), 공개 프로필의 작성글·작성 댓글·수치.
   인기글·하이라이트·갤러리 가젯은 전부터 **누구에게나** 19금 글을 빼고 그대로 둔다(배치 `R__batch_24` 도 `NOT p.adult`).
3. **글 하나를 여는 API 는 403 `POST_ADULT_ONLY`**: 글 보기 `GET /api/posts/{id}` · 댓글 목록·쓰기·고치기·추천 · 투표 · 글 추천 · 신고 · 글 고치기 · 핫딜 상태 바꾸기(`GroupPostGate#resolve` 한 곳 — `AdultContentGate`). 글쓴이의 **지우기만** 예외(본인인증 전에 쓴 19금 글도 지운다).
4. 옛 「확인 단추로 이번 방문만 열기」(board-public-contract 결정 5)와 출생연도 자기 입력 「성인 확인」 화면(`/settings/adult`, 목업)은 없앴다. 설정 메뉴에는 「본인인증」(`/settings/identity`)만 남는다.
5. **말머리 「성인 전용」**(`board_prefixes.adult_only`, shared V152): 고유 말머리만, 게시판 `allowAdult` 가 켜진 게시판에서만 켤 수 있다. 그 말머리를 고른 글은 글쓴이가 체크하지 않아도 19금으로 저장된다.
   관리자가 켜고 저장하면 **그 말머리의 기존 글도 19금**이 된다(감사 기록 `after.adultMarkedPosts` = 바꾼 글 수). 끄면 기존 글은 그대로(글쓴이가 따로 고른 19금일 수 있다).
6. 영상·짤(`video`) 게시판의 「전방·후방」을 성인 전용으로 켠다 — 운영자 값이라 마이그레이션에 넣지 않고 관리자 게시판 편집 화면에서 켠다. 나머지 말머리 글은 누구나 본다.
7. **19금 글은 성인만 쓴다**(아이로빗 판단 — 볼 수 없는 글을 쓰지 않게): 19금을 고르거나 성인 전용 말머리를 고른 글쓰기·고치기가 성인이 아니면 `400 VALIDATION` — 직접 고른 19금이면 `fields.adult`, 말머리 때문이면 `fields.prefixId`(`board.content.adult.identity`). 비회원은 19금 글을 쓸 수 없다.

## 화면
- **user-web 글 보기** `/posts/{id}`: 403 `POST_ADULT_ONLY` 면 본문 대신 「19금 글이에요」 + 사유별 안내 — `LOGIN` [로그인](로그인하면 다시 읽는다) · `IDENTITY` [본인인증하고 보기](`useIdentityGate` 대화상자, 용도 `ADULT_CONTENT` → 통과하면 다시 읽기) · `UNDERAGE` 19세 생일 안내. [돌아가기].
- **user-web 글쓰기·고치기**(`PostEditorForm`): 성인 전용 말머리는 고르기 목록에 「이름 (19금)」, 고르면 19금 체크를 켜고 잠근다(다른 말머리로 옮기면 끈다). 체크 아래 「19금 글은 본인인증으로 만 19세 이상이 확인된 회원만 쓰고 볼 수 있어요」.
- **user-web 게시판 머리**: 19금 허용 게시판 안내 문구를 새 기준으로.
- **admin-web 게시판 편집** `/boards/{slug}` 말머리 줄: 19금 허용이 켜져 있을 때만 「성인 전용」 체크(도움말 툴팁). 19금 허용을 끄면 저장할 때 성인 전용도 꺼서 보낸다.

## API 변경
| API | 바뀐 것 |
| --- | --- |
| `GET /api/posts/{id}` 와 글 하나를 여는 API(위 3) | 19금 글 + 성인 아님 → `403 POST_ADULT_ONLY`, 오류 본문 최상위 `reason`: `LOGIN`·`IDENTITY`·`UNDERAGE`(+ `adultFrom` `YYYY-MM-DD`) |
| 글 목록·검색·최신글·가젯·프로필(위 2) | 성인이 아니면 19금 글이 없다(줄의 `adult` 칸은 그대로 — 성인에게는 `true` 로 온다) |
| `GET /api/boards/{slug}` `prefixes[]` | `adultOnly` 추가 |
| `POST /api/posts` · `PUT /api/posts/{id}` | 성인 전용 말머리면 `adult` 를 서버가 `true` 로 저장 · 19금인데 성인 아님 → `400 fields.adult` 또는 `fields.prefixId` |
| `GET·PUT /api/admin/boards/{id}` `prefixes[]` | `adultOnly` 추가(저장은 빠지면 false) · `allowAdult` 가 꺼진 게시판에 켜면 `400 fields."prefixes[i].adultOnly"`(`board.prefix.adultOnly.needsAdult`) |

## 미확정
- 19금 글이 알림(댓글·추천 알림 등)·쪽지·내 글/내 포인트 내역에 제목으로 나오는 곳은 이번에 거르지 않았다(자기 활동이거나 받는 사람이 정해진 곳).
- 19금 글의 공유 미리보기(OG)·사이트맵은 따로 보지 않았다(글 보기가 403 이라 본문은 나가지 않는다).
