# 방문 통계 — 개인정보 처리방침 문구 초안

운영자가 「관리자 › 약관 › 개인정보 처리방침」에 붙여 넣을 문구 초안이다(2026-11-04 · **3단계 반영 2026-11-11**). **법률 검토를 받은 문구가 아니다** — 게시 전에 담당자(법무·개인정보 보호책임자) 확인을 받는다. 괄호 `[ ]` 안은 사이트 설정에 맞게 고친다. 「설정 › 통계 수집」에서 켠 항목만 남기고 나머지 문단은 지운다.

근거(실제 동작): `docs/features/site-analytics-contract.md`(1·2단계 + 「3단계」) — 브라우저 저장소의 무작위 방문자 ID, 서버는 HMAC 해시만 저장, IP·원본 브라우저 정보(UA) 저장 안 함, 페이지 주소는 화면 단위로 묶어 저장(글·주문 번호 등 개별 번호는 저장 안 함), 원본 기록은 달 단위 보관(기본 이번 달 + 지난달) 뒤 달 조각째 삭제, 하루 방문 판정 2일·지금 접속 10분 뒤 삭제, 주·월 순방문자 판정 표시는 그 주·달이 끝나고 3일 뒤 삭제, 로그인 회원의 주·월 방문 표시(회원 번호)는 같은 기한 + 탈퇴 때 즉시 삭제, 일·시간 단위 합산은 13개월 보관 뒤 월 단위 합산만 남김.

## ○. 방문 통계를 위한 정보 처리

회사는 서비스 개선과 운영 현황 파악을 위해 이용자의 방문 정보를 통계로 만듭니다. 방문 기록은 회원 계정과 연결하지 않으며, 특정 개인을 알아보는 데 쓰지 않습니다. 다만 주·월 단위로 **로그인한 회원 수**를 세기 위해, 그 기간에 로그인 상태로 방문했다는 표시만 회원 번호로 잠시 남깁니다(아래 1·2).

**1. 처리하는 정보**

| 항목 | 내용 |
| --- | --- |
| 방문자 식별값 | 이용자의 브라우저 저장소(로컬 스토리지)에 저장하는 무작위 값. 서버에는 이 값을 그대로 저장하지 않고 되돌릴 수 없게 변환(해시)한 값만 저장합니다. |
| 방문 기록 | 본 화면의 종류와 주소(게시판·안내 화면처럼 정해진 주소. 글·주문·상품 번호 같은 개별 번호는 저장하지 않습니다), 직전에 본 화면, 방문 시각, 들어온 경로(검색·SNS 등 분류와 사이트 주소), 광고 캠페인 표시(UTM), 기기 종류(모바일·태블릿·데스크톱) |
| 로그인 회원 방문 표시 | 로그인한 회원이 그 주·그 달에 한 번 이상 방문했다는 표시(회원 번호와 기간만 — 본 화면·시각은 담지 않습니다). 주·월 단위 로그인 회원 수를 세는 데만 씁니다. |
| [환경 정보] | [브라우저 종류, 운영체제 종류, 화면 너비 구간 — 분류값만 저장하며 브라우저가 보내는 원본 정보는 저장하지 않습니다.] |
| [사이트 내 검색어] | [사이트 안 검색창에 입력한 검색어. 전화번호·이메일 주소·주민등록번호 형태의 검색어는 저장하지 않습니다.] |

IP 주소는 방문 통계에 저장하지 않습니다.

**2. 보유 기간**

- 방문 기록(원본): [이번 달과 지난달]까지 보관하고, 그보다 오래된 달의 기록은 달마다 한꺼번에 삭제합니다(최대 [2]개월).
- 하루 방문자 판정용 값: 2일 후 삭제합니다. 현재 접속 판정용 값: 10분 후 삭제합니다.
- 주·월 방문자 판정용 값(변환한 방문자 식별값): 그 주·그 달이 끝나고 3일 후 삭제합니다.
- 로그인 회원 방문 표시: 그 주·그 달이 끝나고 3일 후 삭제하며, 회원이 탈퇴하면 즉시 삭제합니다.
- 일·시간 단위로 합산한 통계 숫자(방문자 수, 페이지뷰 등)는 개인을 알아볼 수 없는 형태로 13개월 보관하고, 그 뒤에는 월 단위 합산 숫자만 보관합니다.

**3. 브라우저 저장소 사용과 거부 방법**

방문자 식별값은 쿠키가 아닌 브라우저 저장소에 저장되며, 이용자는 다음 방법으로 언제든 거부하거나 지울 수 있습니다.

- 이 처리방침 아래 「방문 통계」에서 **수집 거부**를 켜면 그 브라우저에서는 방문 정보를 보내지 않고 식별값을 지웁니다.
- 같은 곳의 **이 브라우저의 방문 기록 지우기**를 누르면 그 식별값으로 쌓인 방문 기록과 판정용 값을 삭제하고 새 식별값을 만듭니다. 삭제는 접수 후 몇 분 안에 처리됩니다.
- 브라우저 설정에서 사이트 데이터를 지워도 식별값이 삭제됩니다.

수집을 거부해도 서비스 이용에는 제한이 없습니다. 방문 기록은 회원 계정과 연결되지 않으므로, 다른 브라우저나 기기의 기록은 그 브라우저에서 따로 지워야 합니다.

## 운영 메모 (붙여 넣지 않음)

- 원본 보관 `[이번 달과 지난달]`·`[2]` 는 「설정 › 통계 수집 › 원본 기록 보관」 값(2·3·6·12개월, 이번 달 포함)과 맞춘다 — 예 3개월이면 「이번 달과 지난 2개월」·「최대 3」. 설정을 바꾸면 문구도 바꾼다.
- 원본 기록이 꺼져 있으면 「방문 기록(원본)」 줄의 보관 문장을 「방문 기록은 원본을 저장하지 않고 합산 숫자만 남깁니다」로 바꾼다.
- 「방문자·페이지뷰」 수집이 꺼져 있으면 「로그인 회원 방문 표시」 행과 주·월 보관 두 줄을 지운다(그때는 쌓지 않는다).
- 운영자 회원 계정·AI 회원이 보낸 신호는 방문 통계 전체에서 세지 않는다 — 내부 기준이라 처리방침 항목이 아니다.
- 봇·크롤러 집계는 사람 방문이 아니므로(종류별 숫자만) 처리방침 항목이 아니다. 수집 진단도 개인 정보를 담지 않는다.
- 「지우기」는 해시로만 찾으므로 운영자에게 본인 확인을 받을 필요가 없다(식별값을 가진 브라우저만 요청할 수 있음). 처리 현황은 「방문자 통계 › 정보주체 요청」에서 본다. 로그인 회원 방문 표시는 회원 번호로 쌓이므로 「지우기」 대상이 아니라 기간 만료·탈퇴로 지워진다.
- 법무 확인 항목(계약 3단계 결정 ①): 최소 보관 원칙 기준 보관 기간 · 「접속 기록 3개월」(통신비밀보호법, IP 접속 로그)·「1년」(관리자 개인정보 처리 기록)이 이 원본(IP 없음)에 해당하는지 · 로그인 회원 방문 표시를 「회원 계정과 연결하지 않는다」 문장과 함께 써도 되는지.
