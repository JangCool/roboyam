# 게시판 정리 · 스마트 가전 게시판 계약 (**의논 확정 2026-11-26, 적용 전**)

**의도**: 커뮤니티 초기 운영 전략에 맞춰 게시판을 **거의 그대로 두고**, 「스마트 가전」 게시판 하나만 새로 만들고, 겹치는 곳은 말머리로 경계를 정리한다. AI·로봇 이야기가 일반 게시판에도 한 줄씩 보이게 한다.
**근거**: 사용자 결정 2026-11-26 — 게시판 구성은 최대한 유지, 생활 가전 로봇 게시판은 따로, 이름은 「로봇」·「생활」이 겹쳐 헷갈리므로 「스마트 가전」(검색어·범위 기준으로 「우리집 가전」보다 나음), AI·로봇·테크는 그대로.
**적용 방법**: 모두 **관리자 화면 설정**(게시판·말머리·안내문·메뉴)으로 한다 — 코드·마이그레이션 없음. 아래 「개발 필요」만 예외. 기준은 로컬 DB 게시판 30개(2026-11-26 조회) — 운영 서버 구성과 다를 수 있으니 적용 전에 운영 화면에서 다시 본다.

## 1. 새 게시판 「스마트 가전」
| 항목 | 값 |
|---|---|
| 이름 | 스마트 가전 |
| 주소(slug) | `appliance` (후보 — 미확정) |
| 소개 | 로봇청소기부터 펫 로봇까지, 우리 집 똑똑한 가전 이야기 |
| 메뉴 자리 | 맨 윗줄은 그대로. ① 「커뮤니티」 폴더 두 번째 묶음에서 AI·로봇·테크 바로 아래 ② 「핫 로토픽」 바로가기 줄(둘째 줄)에 AI·로봇·테크 바로 뒤 — 바로가기 8개가 된다 |
| 말머리 | 공지 · 로봇청소기 · 물걸레·창문 · 잔디·수영장 · 펫 로봇 · 장난감·교육 · 돌봄 로봇 · AI 가전 · 스마트홈 연동 · 고장·AS · 구매 상담 · 기타 |
| 말머리 모양 | 사이트 기본 그대로(「제목 위」 + 글자 — 데스크톱 둘째 줄 닉네임 뒤 글자, 사용자 2026-11-26) |
| 글 양식(게시판 안내문 묶음) | 제품명 / 집 구조(평수·문턱·러그) / 반려동물 / 예산 / 궁금한 점 |
| 글쓰기 안내 | 정리된 방법은 팁과강좌, 오래 써 본 후기는 사용기에 올리면 매거진에 소개돼요 |

- 「AI 가전」 = AI 냉장고·세탁기·에어컨 등. 로봇·AI 없는 일반 가전은 생활 게시판(「소비·쇼핑」).
- 고정 글 세 개(운영자가 먼저 씀): 「2026 로봇청소기 고르는 법」·「물걸레 냄새·바퀴 걸림 해결」·「로봇청소기 앱 카메라·개인정보」 — 목록 맨 위 고정 줄(지금 기능). 별도 안내 카드는 만들지 않는다(안내문은 링크 없는 평문).
- 안내문(`intro_text`, 목록 머리 회색 상자): 「질문은 제품명·집 구조를 적어 주세요. 정리된 방법은 팁과강좌, 오래 써 본 후기는 사용기에 올리면 매거진에 소개돼요.」
- 화면은 지금 게시판 목록 그대로(PC 두 줄 글 줄·오른쪽 커뮤니티 사이드 / 모바일 말머리 칩 줄·커뮤니티 둘째 줄) — 새 화면 코드 없음. 시안 2026-11-26.
- 함께 보기: 사용기 「스마트 가전」·「로봇·키트」, 핫딜 「로봇」, 팁과강좌 「스마트 가전」·「로봇·메이킹」 — 소개 문구나 고정 글 안의 링크로 둔다(전용 기능 없음).

## 2. AI·로봇·테크 (`ai`) — 그대로
- 「가정·서비스 로봇」 말머리는 **지운다**(끄지 않음 — 사용자 2026-11-26 「숨기지 말고 데이터를 지워」). 고유 말머리라 관리자 화면에서 지울 수 있다. 다만 쓰는 글이 있으면 409 `PREFIX_IN_USE` — 운영 서버에 글이 있으면 그 글을 먼저 스마트 가전으로 옮기거나 다른 말머리로 바꾼 뒤 지운다(로컬 DB 는 0건, 2026-11-26).
- 소개를 「AI와 로봇 기술을 파고들고 직접 만드는 공간」으로 바꾼다.
- 「로봇 제작·DIY」는 말머리로 남긴다. **나누는 기준**: 이 말머리 글이 주 10개 이상으로 3주 넘게 이어지면 「로봇 만들기」 게시판으로 뺀다. 그 전까지 제작 연재는 로봇 소모임 「제작기」.

## 3. 팁과강좌(`tip`)·사용기(`review`) — 정리 글 전용
- 메뉴는 지금처럼 「팁·강좌·사용기」 한 폴더(매거진 /tips) 그대로.
- 질문·잡담 말머리를 뺀다. 사용기는 「후기」도 뺀다(게시판 이름과 겹침). 이 셋은 모든 게시판이 함께 쓰는 **공통 말머리**(질문·후기·잡담·공지, `common_key`)라 지금 관리자 화면에서는 **끄기만** 된다 — 지우려면 개발 필요(미확정 참고). 로컬 DB 에서 쓰는 글 0건.
- 팁과강좌 말머리에 「스마트 가전」 추가. 사용기 말머리에 「스마트 가전」 추가(「로봇·키트」는 그대로 — 키트·DIY 로봇용).
- 글쓰기 안내: 「질문은 스마트 가전·AI·로봇·테크 게시판에서 해 주세요」.

| 스포츠(`sports`) | 로봇 스포츠 |

## 5. 글이 갈 곳 기준 (안내문·공지에 그대로 쓴다)
| 제목 모양 | 갈 곳 |
|---|---|
| 「~나요?」, 짧은 이야기 | 주제 게시판(스마트 가전, AI·로봇·테크 …) |
| 「~하는 법」, 정리 글 | 팁과강좌 |

- 주제 게시판에 좋은 정리 글이 오면 운영자가 팁과강좌·사용기로 옮기거나 하이라이트에 올린다.

## 6. 운영 메모 (전략 요약)
- 힘을 모을 곳: 뉴스 · AI·로봇·테크 · 스마트 가전 · 팁과강좌 · 사용기 · 연애 AI 상담소. 나머지 게시판은 「이번 주 질문」 고정 글 하나 + AI 회원 글로 최소 움직임.
- 운영자 먼저: 기둥글 30개(스마트 가전 고정 글 3개부터) · 로봇 제작 연재 하나.
- 홍보: 네이버 서치어드바이저·구글 서치콘솔 등록, 로봇 격투·실패 영상 해설 쇼츠, 「AI 셋한테 연애상담 받아 봤다」 쇼츠.
- 진행 순서: ① 1~4절 설정 → ② 기둥글 → ③ AI 상담소(정책·법무 확인 뒤 개발).

## 공통 말머리 지우기·다시 넣기 (개발 — 사용자 2026-11-26 「지울 수 있게 개발」)
지금 공통 말머리(질문·후기·잡담·공지, `board_prefixes.common_key`)는 게시판을 만들 때 자동으로 생기고 관리자 화면은 켜기·끄기만 한다. 게시판별로 **행을 지우고**, 지운 것을 **다시 넣을** 수 있게 한다.
- **관리자 화면**(`admin-web` `pages/boards/[slug].vue` 「3. 말머리」 공통 말머리 카드): 카드마다 휴지통. 누르면 카드가 빨간 점선 「저장하면 지워져요 · 되돌리기」(저장 전까지 되돌림), 저장하면 지워진다. 글이 있는 말머리(`usageCount > 0`)는 휴지통이 흐리고 누를 수 없으며 아래에 「이 말머리를 쓴 글 n개를 다른 말머리로 바꾼 뒤 지울 수 있어요」. **체험단(`TRIAL`)은 자물쇠** — 체험단 후기에 서버가 자동으로 다는 말머리라 지우지 않는다. 카드 아래 「지운 공통 말머리 다시 넣기」 줄에 빠진 공통 말머리(질문·후기·잡담·공지 중)를 `+ 이름` 단추로 — 누르면 켜진 카드로 다시 나타나고 저장하면 만들어진다.
- **API**(`PUT /api/admin/boards/{id}` 의 `commonPrefixes[]`, 기존 `{id, active}` 에 더함):
  - `{id, remove: true}` → 그 공통 말머리 행을 지운다. 쓰는 글이 있으면 409 `PREFIX_IN_USE`(고유 말머리와 같은 오류). `TRIAL` 이면 400 `fields.commonPrefixes`.
  - `{id: null, common: "QUESTION"|"REVIEW"|"CHAT"|"NOTICE", active}` → 그 게시판에 없을 때만 새로 만든다(이름·운영진 전용은 지금 공통 규칙 그대로 — 공지는 운영진 전용). 이미 있거나 `TRIAL`·모르는 키면 400 `fields.commonPrefixes`.
  - 빠진 항목은 지금처럼 그대로 둔다(지우라는 뜻 아님).
  - 권한·감사: 지금 말머리 변경과 같다(`board.manage`, `BOARD_UPDATE`). 감사 before/after 에 공통 말머리 **있는 것 목록**도 남겨 지우기·다시 넣기가 보이게 한다.
- **조회**: 지금 응답 그대로(있는 공통 말머리만 `prefixes[]` 에 `common` 키로). 빠진 공통 말머리는 화면이 공통 4개 목록에서 계산한다.
- **설치 프리셋**: 내보내기·적용에서 지운 공통 말머리가 다시 생기지 않게 한다(내보낸 게시판에 없는 공통 말머리는 적용 뒤에도 없음).
- 공개 화면(user-web)은 바뀌지 않는다 — 있는 말머리만 받아 그린다.

## 개발 필요 (지금 기능에 없음)
- 글 「해결」 표시(질문 글 해결됨) — 없음. 하려면 별도 기능.
- 말머리별 글 양식 — 지금 글 양식은 **게시판 하나에 하나**(`boards.write_template`, 새 글에만 미리 채움). 「구매 상담」·「고장·AS」를 고를 때만 채우려면 개발 필요. 그 전에는 게시판 전체 양식으로 둔다.

## 미확정
- **공통 말머리(질문·후기·잡담) 처리**: 사용자는 「숨기지 말고 지워」를 원함. 공통 말머리는 게시판을 만들 때 자동으로 생기고 관리자 화면은 켜기·끄기만 한다 → ① 끄기로 대신(데이터만 남고 화면·글쓰기 어디에도 안 보임) ② 게시판별로 공통 말머리를 지울 수 있게 개발. 새 스마트 가전 게시판도 질문·후기·잡담·공지가 자동으로 붙는다 — 구매 상담·고장·AS 가 질문을 대신하므로 같은 방식으로 정리.
- 「AI 가전」 기준: 스스로 움직이는 것은 각 로봇 말머리, 제자리 AI 가전(냉장고·세탁기·에어컨·공기청정기)만 「AI 가전」 — 공지 고정 글에 한 줄로.
- 주소(slug) `appliance` 확정.
- 설치 프리셋(`install-presets/irobit.structure.json`)·데모 팩에도 반영할지.
- 하이라이트에 다른 게시판 글을 올려 /tips 매거진에 보이게 할 수 있는지 확인.
- 끈 말머리(가정·서비스 로봇·질문·잡담·후기)가 달린 기존 글이 목록에서 어떻게 보이는지 확인.
