# 글 태그 계약 (**시안 확정 2026-11-15**)

**의도**: 글쓴이가 글에 태그(#AI · #반도체 · #테슬라 …)를 달고, 운영자가 고른 태그를 홈 새소식 가젯의 탭으로 보여 준다(PC·모바일). 팁·강좌·사용기 매거진의 태그 칩(지금 목업)도 같은 태그로 실제 연결한다.

## 화면
- **새소식 가젯 태그 탭**(시안 2 — 지금 새소식 모양은 그대로): 「전체 · #태그 · #태그 …」 글자 탭(인기글 기간 탭과 같은 모양 — 고른 탭 굵게 + 강조색 밑줄, `#` 은 흐린 색).
  - PC: 가젯 제목 줄, 제목 바로 옆(더보기는 오른쪽 끝 그대로). 모바일(한 열): 제목 줄 바로 아래 한 줄, 넘치면 가로로 밀기, 누르는 높이 32px.
  - 누르면 페이지를 옮기지 않고 목록만 그 태그 글로 바꾼다(첫 글 사진 줄·요약·두 열·모바일 쪽 넘기기 그대로 — 그 태그 글로). 「전체」 = 지금 목록. 더보기 = 고른 태그면 `/boards/{게시판}?tag={태그}`.
  - 가젯은 서버를 부르지 않는다 — 탭마다 글을 한 번에 받는다(인기글 기간 탭과 같은 방식).
- **글쓰기·고치기**: 게시판 옵션 「태그 쓰기」를 켠 게시판만 태그 입력 칸(제목·본문 아래). 칩으로 넣기(엔터·쉼표·스페이스), `#` 은 떼고 저장, 지우기 ×. 최대 5개.
- **글 보기**: 본문 아래 태그 칩(`#태그`) — 누르면 그 게시판 목록 태그 거르기.
- **게시판 목록**: 주소 `?tag=` 이면 그 태그 글만 + 목록 머리에 「#태그 ✕」(누르면 거르기 풀기). 쪽 번호·정렬은 그대로.
- **매거진(`/tips`)**: 태그 칩 = 묶음 게시판(tip·review)에서 최근 많이 달린 태그 위 10개(실제 값). 칩을 누르면 `/tips?tag=`(최신 글 목록을 그 태그로 거름 — 지금 `/search?q=` 임시를 바꿈). 글 줄의 태그(1~3개 표시)도 실제 값.
- **관리자**
  - 게시판 설정(일반 게시판): 「태그 쓰기」 켬/끔(게시판 기본값을 따름 · 기본 꺼짐). 뉴스·팁과강좌·사용기는 켬.
  - 새소식(글 목록) 가젯 ⚙ 내용 탭: 「태그 탭」 — 최대 8개, 순서대로. 고르기 칸에 최근 30일 많이 달린 태그 추천(대상 게시판 범위 안, 달린 수와 함께) + 직접 입력. 비우면 탭 없음.

## 필드·검증
- 태그 글자: 앞뒤 공백 제거, 안쪽 공백 하나로, 앞의 `#` 떼기, 1~20자, 줄바꿈·제어 문자·`#`·`,` 금지. 같은지 비교는 영문 대소문자 무시(저장은 처음 쓴 모양). 글당 최대 5개, 겹치면 하나.
- 태그를 쓰지 않는 게시판에 보내면 무시(오류 아님). 고치기에서 `tags` 를 빼면 그대로, 빈 목록이면 모두 지움.
- 가젯 config `tagTabs`(문자열 목록, 최대 8 — 위 규칙으로 정규화). 공개 데이터 `tagged: { [태그]: PostFeedRow[] }`(탭마다 가젯 `count` 만큼, 대상 범위·제외할 게시판·첫 글 요약 규칙 그대로).

## 권한·정책
- 태그는 글쓴이(회원·비회원 글 모두 — 글쓰기 권한 그대로)가 단다. 운영자가 글을 고칠 때도 바뀐다. 금칙어 검사는 제목·본문과 같은 규칙으로 태그에도.
- 가려진·삭제된 글은 태그 목록·추천 수에서 빠진다.

## API 후보
- 글 쓰기 `POST /api/posts`·고치기 `PUT /api/posts/{id}` 에 `tags: string[]`. 글 보기 응답에 `tags`.
- 게시판 글 목록 `GET /api/boards/{slug}/posts?tag=`(정확히 같은 태그, 대소문자 무시).
- 게시판 공개 정보에 `tagsEnabled`.
- 관리자 태그 추천 `GET /api/admin/tags/popular?boards=slug,slug&days=30&limit=30` → `[{ name, count }]`(boards 없으면 전체).
- 매거진 `GET /api/tips` 의 `tags: {name,count}[]` 실제 값, 글 줄 `tags`, `GET /api/tips/posts?tag=`.

## 데이터
- 새 표 `post_tags(post_id, tag, tag_key, created_at)` — `tag_key` = 비교용(소문자·공백 정리), (post_id, tag_key) 유일, (tag_key, post_id) 색인. shared 마이그레이션 V215.
- 게시판 `tags_enabled`(NULL = 기본값 따름) + `board_defaults.tags_enabled`(기본 false). V215 가 뉴스·tip·review 게시판을 켠다.
- 아이로빗 새소식 가젯 `tagTabs`: AI · 반도체 · 테슬라 · 휴머노이드 · 엔비디아(V215 · 코드 기본 · 설치 프리셋).
- 데모 원고: 뉴스·팁·사용기 글에 `tags`(CONTENT-FORMAT 에 칸 추가, 로더가 글 쓸 때 보냄).

## 미확정
- 태그 하나로 모아 보는 사이트 전체 태그 화면(`/tags/{태그}`)은 이번 범위 밖.
