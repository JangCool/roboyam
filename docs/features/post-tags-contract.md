# 글 태그 계약 (**시안 확정 2026-11-15**)

**의도**: 글쓴이가 글에 태그(#AI · #반도체 · #테슬라 …)를 달고, 운영자가 고른 태그를 홈 새소식 가젯의 탭으로 보여 준다(PC·모바일). 팁·강좌·사용기 매거진의 태그 칩(지금 목업)도 같은 태그로 실제 연결한다.

## 화면
- **새소식 가젯 태그 탭**(시안 2 — 지금 새소식 모양은 그대로): 「전체 · #태그 · #태그 …」 글자 탭(인기글 기간 탭과 같은 모양 — 고른 탭 굵게 + 강조색 밑줄, `#` 은 흐린 색).
  - PC: 가젯 제목 줄, 제목 바로 옆(더보기는 오른쪽 끝 그대로). 모바일(한 열): 제목 줄 바로 아래 한 줄, 넘치면 가로로 밀기, 누르는 높이 32px.
  - 누르면 페이지를 옮기지 않고 목록만 그 태그 글로 바꾼다(첫 글 사진 줄·요약·두 열·모바일 쪽 넘기기 그대로 — 그 태그 글로). 「전체」 = 지금 목록. 더보기 = 고른 태그면 `/boards/{게시판}?tag={태그}`.
  - 가젯은 서버를 부르지 않는다 — 탭마다 글을 한 번에 받는다(인기글 기간 탭과 같은 방식).
- **글쓰기·고치기**: 게시판 옵션 「태그 쓰기」를 켠 게시판만 태그 입력 칸(제목·본문 아래). 칩으로 넣기(엔터·쉼표·스페이스), `#` 은 떼고 저장, 지우기 ×. 최대 5개.
- **글 보기**: 본문 아래 태그 칩(`#태그`) — 누르면 그 게시판 목록 태그 거르기.
- **게시판 목록**: 주소 `?tag=` 이면 그 태그 글만 + 목록 머리에 「#태그 ✕」(누르면 거르기 풀기). 쪽 번호·정렬은 그대로.
- **매거진(`/tips`)**: 태그 칩 = 묶음 게시판(tip·review)에서 최근 많이 달린 태그 위 10개(실제 값). 칩을 누르면 `/tips?tag=`(최신 글 목록을 그 태그로 거름 — 지금 `/search?q=` 임시를 바꿈). 글 줄의 태그(1~3개 표시)도 실제 값.
- **관리자**
  - 게시판 설정(일반 게시판): 「태그 쓰기」 켬/끔(게시판 기본값을 따름 · 기본 꺼짐). 뉴스·팁과강좌·사용기는 켬.
  - 새소식(글 목록) 가젯 ⚙ 내용 탭: 「태그 탭」 — 최대 8개, 순서대로. 고르기 칸에 최근 30일 많이 달린 태그 추천(대상 게시판 범위 안, 달린 수와 함께) + 직접 입력. 비우면 탭 없음.

## 필드·검증
- 태그 글자: 앞뒤 공백 제거, 안쪽 공백 하나로, 앞의 `#` 떼기, 1~20자, 줄바꿈·제어 문자·`#`·`,` 금지. 같은지 비교는 영문 대소문자 무시(저장은 처음 쓴 모양). 글당 최대 5개, 겹치면 하나.
- 태그를 쓰지 않는 게시판에 보내면 무시(오류 아님). 고치기에서 `tags` 를 빼면 그대로, 빈 목록이면 모두 지움.
- 가젯 config `tagTabs`(문자열 목록, 최대 8 — 위 규칙으로 정규화). 공개 데이터 `tagged: { [태그]: PostFeedRow[] }`(탭마다 가젯 `count` 만큼, 대상 범위·제외할 게시판·첫 글 요약 규칙 그대로).

## 권한·정책
- 태그는 글쓴이(회원·비회원 글 모두 — 글쓰기 권한 그대로)가 단다. 운영자가 글을 고칠 때도 바뀐다. 금칙어 검사는 제목·본문과 같은 규칙으로 태그에도.
- 가려진·삭제된 글은 태그 목록·추천 수에서 빠진다.

## API 후보
- 글 쓰기 `POST /api/posts`·고치기 `PUT /api/posts/{id}` 에 `tags: string[]`. 글 보기 응답에 `tags`.
- 게시판 글 목록 `GET /api/boards/{slug}/posts?tag=`(정확히 같은 태그, 대소문자 무시).
- 게시판 공개 정보에 `tagsEnabled`.
- 관리자 태그 추천 `GET /api/admin/tags/popular?boards=slug,slug&days=30&limit=30` → `[{ name, count }]`(boards 없으면 전체).
- 매거진 `GET /api/tips` 의 `tags: {name,count}[]` 실제 값, 글 줄 `tags`, `GET /api/tips/posts?tag=`.

## 데이터
- 새 표 `post_tags(post_id, tag, tag_key, created_at)` — `tag_key` = 비교용(소문자·공백 정리), (post_id, tag_key) 유일, (tag_key, post_id) 색인. shared 마이그레이션 V215.
- 게시판 `tags_enabled`(NULL = 기본값 따름) + `board_defaults.tags_enabled`(기본 false). V215 가 뉴스·tip·review 게시판을 켠다.
- 아이로빗 새소식 가젯 `tagTabs`: AI · 반도체 · 테슬라 · 휴머노이드 · 엔비디아(V215 · 코드 기본 · 설치 프리셋).
- 데모 원고: 뉴스·팁·사용기 글에 `tags`(CONTENT-FORMAT 에 칸 추가, 로더가 글 쓸 때 보냄).

## 집계 (사용자 결정 2026-11-15)
- 「많이 달린 순」(관리자 추천 `GET /api/admin/tags/popular` · 매거진 `/api/tips` 태그 칩)은 요청마다 세지 않고 **미리 세어 둔 표**를 읽는다 — `post_tag_daily(day, board_id, tag_key, tag, post_count)`, PK (day, board_id, tag_key) + 색인 (board_id, day). shared V216.
  - `day` = 글을 쓴 **한국 날짜**(Asia/Seoul, `posts.created_at`), `tag` = 그날 그 게시판에서 가장 많이 쓴 모양, `post_count` = 그 태그가 달린 보이는 글 수.
  - 셀 글 = 예전 질의와 같은 조건(지우지 않음·게시·예약 삭제 전 · 숨김 아님(기간 숨김 끝남 포함) · 비밀글·비멤버에게 안 보이는 소모임 글 아님). 꺼진 게시판도 센다.
  - 읽기(`PostTagQueries#popular`): `day ≥ 오늘 − days + 1`(오늘 포함 days 일) · 게시판 범위 · `sum(post_count)` 내림차순(같으면 열쇠) · limit. 이름은 기간 안 합이 가장 큰 모양. 응답 `[{name,count}]` 그대로.
- **DB 크론 하나** `post-tag-daily`(R__batch_44 · 10분마다): 날 단위로 지우고 다시 넣는다(한 날 = 한 트랜잭션). 다시 셀 날 =
  1. 어제·오늘
  2. **지난 계산 뒤로 바뀐 태그 글**이 쓰인 날(최근 31일 안, 설정 `window_days`). **post_tags 에서 출발**한다 — Snowflake id 바닥으로 post_tags 를 좁히고 posts 는 기본 키로 붙인다(posts 를 시각 칸으로 훑지 않고 새 색인도 없다). 바뀜 = 글의 `updated_at`(지우기·되살리기·신고/운영 숨김·숨김 풀기·고치기(태그만 고쳐도)·게시판 이동·소모임 공개 범위·나가기 가리기)·`hidden_until`/`delete_scheduled_at` 이 지난 계산과 지금 사이에 지남·소모임 비활성/다시 열기(`groups.deactivated_at`·`reactivated_at`)·새 태그(`post_tags.created_at`).
  3. **바뀐 날 표시**의 날(최근 31일 안) — 태그 저장 한 곳(`PostTagStore#replace` — 쓰기·고치기·지우기)이 태그를 실제로 바꾸면(넣기·빼기·표기 변경, 차례만 바뀐 것은 아님) 그 글의 「작성일(KST) · 게시판」을 `post_tag_dirty_days`(V216)에 넣는다. 그래서 오래된 글에서 태그를 **모두** 뺀 경우(post_tags 행이 없어 ②로 못 찾음)도 잡힌다.
     - 표는 넣기만 하는 일련번호 키(id identity, day, board_id, created_at) — 같은 날·게시판을 여러 글이 동시에 고쳐도 키 충돌로 글 저장이 실패하지 않게 (day, board_id) 키 대신 이렇게 했다(같은 날 줄이 여럿이어도 그 날은 한 번 센다).
     - 배치는 그 날을 다시 세는 트랜잭션에서 표시를 **세기 전에** 지운다(센 뒤 지우면 그 사이 COMMIT 된 변경의 표시가 세지 않은 채 지워질 수 있다). 31일보다 앞선 날의 표시는 세지 않고 지운다.
  - 지난 계산 시각 = 이 배치의 마지막 성공 실행(`batch_runs`) 시작 − 5분. 성공 기록이 없으면 최근 31일을 모두 센다.
  - 지운 게시판(글 행이 지워짐)의 집계 줄은 실행마다 지운다.
- **새벽 보정** `post-tag-daily-recent`(R__batch_44 · 매일 04:50 KST): 최근 7일(설정 `recent_days`, 1~31)을 통째로 다시 센다 — 위 신호로 못 잡는 예외적인 틀어짐(DB 를 직접 고친 경우 · 수정 시각을 안 바꾸는 새 경로 등)을 하루 안에 바로잡는 안전망. 보정은 대부분 글이 올라온 뒤 며칠 안에 일어나므로 30일 전체는 세지 않는다(사용자 2026-11-15). 태그 달린 글만 읽어 가볍다.
  - **새벽에 31일을 통째로 다시 세는 크론은 두지 않는다**(부하). 31일보다 앞선 날은 마지막으로 센 값 그대로.
- 그래서 추천·칩은 **최대 10분 늦다**. 설치 직후·크론이 아직 안 돈 때를 위해 마이그레이션(R__batch_44) 끝에서 최근 31일을 한 번 센다. pg_cron 이 없으면 정기 계산이 없다(배치 목록 「사용 불가」).

## 글쓰기 추천 (사용자 2026-11-15 — 같은 태그를 조금 다른 이름으로 달지 않게)
- 글쓰기·고치기 태그 칸이 그 게시판에서 쓰인 태그를 한 번 받는다 — `GET /api/boards/{slug}/tags` → `[{name,count}]`(집계 표 `post_tag_daily` 의 모든 날 합, 많이 쓴 순, 최대 300 · 최대 10분 늦음 · 「태그 쓰기」가 꺼졌으면 빈 목록 · 없거나 소모임 게시판 404 · 꺼진 게시판 403). 소모임 글은 추천 없음.
- 치는 동안 칸 아래 목록: 띄어쓰기·대소문자를 무시하고 「포함」하는 태그, 앞에서부터 맞는 것 먼저 → 많이 쓴 순, 최대 6개, 글 수 함께. 정확히 같은 태그가 없으면 맨 아래 「새 태그로 넣기」. ↑·↓·엔터·Esc, 누르면 넣기. 추천이 하나도 없으면 목록을 열지 않는다.
- 칸이 비었으면 「이 게시판에서 많이 쓴 태그」 칩(넣지 않은 것 위 8개) — 누르면 넣는다.
- **띄어쓰기·대소문자만 다른 태그는 기존 모양으로**: 화면은 넣을 때 바꾸고 칸 아래 알린다. 서버도 저장 때(`PostTagStore#replace`) 그 게시판 집계 표에서 띄어쓰기를 뺀 열쇠(`PostTags#compact`)가 같은 모양 중 가장 많이 쓴 것으로 바꾼다(「ai」 → 「AI」). 비교 열쇠 `tag_key` 규칙과 기존 데이터는 그대로(마이그레이션 없음).

## 미확정
- 태그 하나로 모아 보는 사이트 전체 태그 화면(`/tags/{태그}`)은 이번 범위 밖.
