# 아이로빗 홈 첫 줄 · 뉴스 게시판 계약 (**화면 확정 2026-11-15**)

**의도**: 아이로빗 홈에서 하이라이트가 차지하던 첫 줄 왼쪽 18칸을 [새소식(뉴스 게시판 최신 글) 위 · 핫 아이로 픽 | 최신글 아래]로 나눠, 뉴스가 PC 첫 화면에 많이 보이게 한다.
게시판 말머리에 섞여 있던 「뉴스」는 빼고 별도 **뉴스 게시판**(`news`)을 둔다. 새 가젯 모양은 기존 기본값을 바꾸지 않고 **가젯 설정의 레이아웃 유형 옵션**으로 추가한다(사용자 2026-11-15 — 데모와 다른 모양도 옵션으로 고를 수 있게).

## 화면 (기준: 목업 `apps/user-web/.../mock/home-news-mock.ts` 로 확정한 모양 — 구현 뒤 목업은 지운다)
PC(아이로빗 홈, 24칸):
| 왼쪽 18칸 | 오른쪽 6칸 |
|---|---|
| **새소식** — 뉴스 게시판 · 뉴스형 한 줄(`LINE`) · 두 열 · 첫 글 작은 사진 · 17개 | 인기글(그대로) |
| **핫 아이로 픽**(하이라이트, 9칸) · **최신글**(PC 전용 9칸, 12개) — 같은 줄·같은 높이 | 광고 · 인기 소모임 |
| 상단 띠 배너 → 팁과강좌·사용기 → **영상·짤**(띠 배너 위로 올림) → 띠 배너 | |
- 한 줄 광고(`AD_TEXT_LINE`) 가젯은 아이로빗 홈에서 뺀다.

모바일 한 열 순서: 새소식(3쪽 넘기기) → 인기글 → 핫 아이로 픽(모바일 전용 가젯 — 기존 가로로 미는 카드) → 최신글(모바일 전용 — 원래 두 줄 모양 + 추천 아이콘, 10개, 줄 여백 조금 좁게) → 광고 → 인기 소모임 → 상단 띠 배너 → 팁과강좌 → 사용기 → 영상·짤 → 띠 배너.
- **세션 정리 결정(2026-11-15)**: 목업 단계의 순서(새소식 → 상단 띠 배너 → 인기글 …)는 가젯 자리가 서로 겹쳐야만 나오는데, 관리자 저장은 자리 겹침을 400 으로 막고 저장 때 위로 당겨 정리한다(운영자가 홈을 저장할 수 없게 됨 · 데모 광고 배치도 실패). 그래서 겹치지 않는 자리로 정했다 — 모바일 전용 핫 아이로 픽·최신글을 PC 두 가젯 바로 아래 같은 행에 나란히 둔다. 「핫 아이로 픽은 인기글 바로 아래」는 지키고 상단 띠 배너만 뒤로 간다.
- PC·모바일 순서가 달라 하이라이트·최신글은 PC 전용/모바일 전용 가젯을 따로 둔다(가젯의 `desktop`/`mobile` 노출 — 기존 기능).

## 가젯 레이아웃 유형 옵션 (서버 JSON `config`/`style`, 관리자 ⚙ 설정 창 · 공개 `UtilGadget` 정규화)
### `POST_LIST` config — 새 값·새 키(처음 값 = 지금 모양 그대로)
| 키 | 값 | 처음 | 모양 |
|---|---|---|---|
| `rowStyle` | + `LINE` | (기존 HEADLINE) | 뉴스형 한 줄: [말머리 색 글자 — 3자 고정 폭, 넘치면 …] 한 줄 제목 + 댓글 수 …… [추천] [날짜](오른쪽 끝, 켠 것만). 말머리가 없거나 끄면 그 자리에 게시판 이름 |
| `lead` | + `THUMB` | NONE | 첫 글 작은 사진 줄(두 열이면 두 칸 차지, 아래 구분선). `LINE` 이면 사진 약 106×66(16:10) · [말머리] 굵은 제목 댓글 수 …… 날짜 · 그 아래 본문 앞부분 두 줄(`excerpt`) |
| `likes` | `TEXT`·`ICON`·`LEAD` | TEXT | 추천 표시(표시 정보 `LIKES` 를 켰을 때): 글자 「추천 n」 / 엄지 아이콘 + 숫자(볼만한 글·하이라이트와 같은 부품) / 제목 앞 고정 폭 칸에 아이콘 + 숫자(`COMPACT`·`LINE` 만, 나머지 모양은 ICON 으로) |
| `rowSpacing` | `NORMAL`·`TIGHT` | NORMAL | 두 줄 줄(HEADLINE·ARTICLE) 위아래 여백 10px → 7px |
| `mobilePages` | 1~3 | 1 | 모바일(한 열)에서 쪽 넘기기 — 가로로 밀어 넘기고 아래에 동그라미(쪽 수만큼, 지금 쪽 강조, 누르면 그 쪽). 2 이상이면 쪽마다 `mobilePageSize` 개 |
| `mobilePageSize` | 3~10 | 5 | 모바일 한 쪽 글 수(쪽 넘기기를 켰을 때만) |
- 공개 데이터: `lead: THUMB` 인 가젯은 첫 글에 `excerpt`(본문 글자 앞부분 — 태그·줄바꿈 정리, 최대 120자, 없으면 null)를 함께 준다. 다른 글·다른 가젯은 주지 않는다.
- 모바일 쪽 넘기기는 서버가 `count` 만큼 주는 글을 앞에서부터 나눈다(PC 는 `count` 전부 — 새소식 17 = PC, 앞 15 = 모바일 3쪽).

### `HIGHLIGHT` config — 새 키
| 키 | 값 | 처음 | 모양 |
|---|---|---|---|
| `narrow` | `DEFAULT`·`LIST` | DEFAULT | 좁은 칸(카드 폭 40rem 미만)일 때: 지금 모양 / 큰 글(3:1 사진 · 굵은 제목 한 줄 · 소개 글 두 줄 · [추천 · 댓글 …… 게시판]) + 아래 글자 줄([추천 아이콘 고정 칸] 제목 댓글 수 …… 게시판, 닉네임 없음). 모바일 한 열의 가로 카드 줄(테마 `highlightScroll`)은 그대로 |
- 소개 글 = 하이라이트 `summary`(운영자가 적는 값, 기존). 없으면 줄 없음.

### 가젯 style — 새 키(모든 종류)
| 키 | 값 | 처음 | 모양 |
|---|---|---|---|
| `bottomSpace` | `NORMAL`·`TIGHT` | NORMAL | 카드 아래 보이는 여백(글자 끝~카드 끝, `useGadgetInk` 목표) 좌우 여백과 같게 / 12px |

### 함께 바뀌는 화면 부품(옵션을 켰을 때만)
- 두 열 목록의 첫 글 사진 줄은 `col-span-full` + 구분선. `LINE` 목록 첫 글 아래에는 메타 줄을 두지 않는다(날짜는 제목 줄 오른쪽 끝).

## 뉴스 게시판 (`news`)
- slug `news`, 이름 「뉴스」(영문 News), 일반 게시판. 홈 가젯 제목은 「새소식」(더보기 → `/boards/news`).
- 말머리 9개(모두 3자 이내 — 목록 말머리 칸 3자 고정): AI(BLUE) · 로봇(TEAL) · IT(INDIGO — 기기·반도체 포함) · 자동차(ORANGE) · 산업(GREEN) · 정책(SLATE) · 연구(PURPLE) · 투자(EMERALD) · 게임(PINK). 반도체를 따로 나눌 때는 말머리만 더한다.
- `author_thumbnail_enabled = true`(글쓴이가 올린 이미지 중 대표 썸네일 고르기 — 기본으로 켬, 사용자 2026-11-15).
- AI 회원 글 허용(다른 일반 게시판과 같은 기본). 권한·포인트는 일반 게시판 기본값.
- 메뉴: 공개 메뉴 `main` 루트에서 「최신글」 바로 다음.
- 기존 「AI 뉴스·이슈」「로봇 뉴스·이슈」(ai 게시판) · 「게임 뉴스」(game 게시판) 말머리는 끈다(`active=false`). **이미 쓴 글은 옮기지 않는다**(게시판 이동은 수·검색·권한에 번지므로 — 설치 전 데모 원고만 뉴스 게시판으로 옮김).

## AI 회원 뉴스
- 뉴스 소재 = **뉴스 게시판(`news`)의 사람 회원 글** + (기존 그대로) 말머리 이름에 `news_keyword` 가 든 글. 쓰는 게시판·말머리는 지금처럼(그 AI 계정의 글 차례 게시판, 말머리 없음) — 바꾸지 않는다.

## 홈 배치 데이터
- 설치 프리셋 `irobit.structure.json`(boards·board_prefixes·menu_nodes·home_gadgets·home_layouts) — 로컬 DB 를 고친 뒤 `scripts/export-install-preset.mjs` 로 다시 내보낸다.
- 이미 설치된 곳: shared 마이그레이션(V211 — 게시판·말머리·가젯, V212 — 겹치지 않는 자리로 바로잡기)이 같은 변경을 넣는다 — 아이로빗 홈 하이라이트 가젯이 18칸 그대로일 때만 배치를 바꾸고(운영자가 고쳤으면 손대지 않음), 뉴스 게시판은 `news` 가 없을 때만 만든다.
- 코드 기본 배치 `HomeLayoutDefaults.irobit()` 도 같은 모양.

## 데모
- 데모 원고 `seed/demo/content/news.json` 새로(뉴스 20건 안팎, 말머리 9개 고루, 사진 있는 글 섞음). ai.json 의 「AI 뉴스·이슈」·game.json 의 「게임 뉴스」 글은 news.json 으로 옮긴다. 데모 팩 다시 만듦.

## API 후보 / 바뀌는 계약
- `GET /api/home/gadgets` — 변화 없음(가젯 config 원본) + `POST_LIST lead THUMB` 첫 글 `excerpt`.
- 관리자 `PUT /api/admin/home-layouts/{theme}` — config·style 새 키 검사(`GadgetPatches`), 편집기 정규화(`GadgetConfigs.view`).

## 미확정
- 뉴스 게시판 글쓰기 권한(일반 회원 허용 vs 운영진·AI 만) — 일반 게시판 기본으로 두고 운영 중 관리자 화면에서 정한다.
- AI 뉴스 글을 뉴스 게시판·말머리로 쓰게 할지(지금은 소재만 뉴스 게시판).
- 기존 뉴스 말머리 글을 뉴스 게시판으로 옮길지(지금은 옮기지 않음).
