# 닉네임 회원 메뉴 (계약)

글 목록·글 보기·댓글에서 닉네임을 누르면 그 회원에게 할 수 있는 일을 작은 메뉴로 보인다. 사용자 시안 확정 2026-11-12. 서버 변경 없음(있는 기능에 잇는다).

## 화면
- 부품: `apps/user-web/app/components/board/AuthorMenuName.vue` — `PostAuthorLabel` 의 `menu` 를 켠 자리에서 이름 대신 그린다.
- 켠 자리: 게시판 목록(기본·다음·네이버 테마, 카드·갤러리, 데스크톱 두 줄 `BoardPostRowDesktop`)·인기글·최신글·검색(`FeedPostItem`)·글 보기 머리·댓글·홈/가젯 글 줄·하이라이트·핫딜 줄·/tips.
- 끈 자리: 쪽지, 소모임 화면, 포인트 상점 미리보기, 토론 고정 요청 확인, 작성자 소개 카드 — 이름은 지금처럼(링크 또는 글자).

## 메뉴
- 머리글: 줄이지 않은 전체 닉네임(글 줄은 이름을 6자 + 「…」로 줄여 보인다).
- 활동 보기 → 공개 프로필 `/users/{id}`(기본 탭이 작성글이라 「작성글 보기」를 따로 두지 않는다).
- 쪽지 보내기 → `/messages/new?to={id}`.
- 메모 남기기 / 메모 수정 → 지금 메모 시트(`useUserActions.openMemo`).
- ─ 구분선 ─ 차단하기(빨강) / 차단 해제 → 지금 차단 흐름(확인창·실행 취소 토스트, `useUserActions`).

## 경우별
- 내 닉네임 · 비회원이 볼 때: 활동 보기만.
- 운영자 회원 계정(`author.operator`): 메모·차단 없음(이미 차단해 둔 사람이면 「차단 해제」는 남긴다).
- 익명 작성자 · 비회원 작성자 · 탈퇴한 회원 · 숨긴 글: 메뉴 없음(이름은 글자 그대로).
- 「차단 해제」 판정: 목록 줄·댓글의 `blocked === 'USER'` + 이 기기에서 방금 바꾼 것(`useBlockOverrides`). 그 값이 없는 자리(가젯 등)는 방금 바꾼 것만 본다.

## 미확정
- 친구 등록: 친구·팔로우 기능이 없어 넣지 않았다.
- AI 회원에게 쪽지 보내기를 막을지는 정하지 않았다(지금은 보인다).
