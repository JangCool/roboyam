# 게시판 추천 글 계약 (**시안 확정 2026-11-26, 개발 중**)

**의도**: 게시판마다 목록 위에 「추천 글」 카드 최대 3장을 보인다. 운영자가 그 게시판에 고른 글이 먼저, 3칸이 안 차면 그 게시판에서 추천이 많은 글로 자동으로 채운다. 운영자가 아무것도 안 해도 게시판마다 볼거리가 생기게 하는 것이 목적.
**근거**: 사용자 2026-11-26 — 「따로 개발해」, 「추천글은 게시판마다 추천글」, 「고른 글 + 자동」. 새 기능을 만들지 않고 **하이라이트**(`highlights`, 놓일 곳 `place` — tips-contract 「페이지별 하이라이트 + 자동 채움」)에 **게시판 곳**을 더한다. 자동 채움 규칙은 /tips 「이번 주 추천」과 같은 방식.

## 화면 (시안 2026-11-26)
- **공개 게시판 목록**(`apps/user-web/app/pages/boards/[slug]/index.vue`): 안내문(·투자 고지·19금 안내) 아래, 말머리 줄 위. PC = 카드 3장 한 줄(같은 폭), 모바일 = 옆으로 밀어 보는 카드(한 장 약 72% 폭). 카드 = 작은 글자 한 줄 + 큰 글자 제목 한 줄(말줄임), 누르면 그 글. 카드가 하나도 없으면 줄을 그리지 않는다.
  - 운영자가 고른 글: 작은 글자 = 하이라이트 「요약」(한 줄로 자름, 비었으면 「운영자 추천」), 큰 글자 = 하이라이트 「노출 제목」(없으면 글 제목).
  - 자동으로 채운 글: 작은 글자 = 「추천 n」(+ 말머리가 있으면 「· 말머리」), 큰 글자 = 글 제목.
  - 색은 게시판 표시색 계열의 옅은 바탕(없으면 중립). 다크 모드 대비 지킴.
- **관리자 › 하이라이트**(곳별 화면 — 왼쪽 곳 카드 목록): 곳 목록 아래 「게시판」 묶음 — 고른 글이 있거나 자동 채우기를 끈 게시판만 줄로 보이고, 「+ 게시판 곳 추가」로 게시판을 골라 그 게시판 곳을 연다. 게시판 곳 화면 = 기존 곳 화면 그대로(글 추가·순서·노출·기간·노출 제목·요약) + 머리에 「위에서 3개까지 보여요」 + 스위치 「모자라면 추천 많은 글로 자동 채우기」(기본 켬).

## 규칙
- **곳 키**: 게시판 id 로 `board-{boardId}`(`HighlightPlaces.KEY` 모양 안). `board-` 로 시작하는 키는 게시판 곳 전용 — 가젯 페이지 키로 못 쓰게 막는다. 게시판이 지워지면(또는 비활성) 그 곳 하이라이트는 공개에 안 보인다(정리 방식은 구현 판단).
- **대상 게시판**: 일반 게시판(`kind = GENERAL`)만. 핫딜(DEAL)·소모임 게시판은 제외.
- **표시 순서**: 고른 글(노출 켬·기간 안·글이 보이는 상태, 관리자 순서) → 자동 채움. 최대 3. 같은 글은 한 번.
- **자동 채움**(게시판별 스위치가 켜졌을 때, 기본 켬): 그 게시판 글 중 최근 7일 추천순 → 모자라면 최근 30일 추천순. **추천 1 이상만**. 공지·고정 글, 숨김·삭제·신고로 가려진 글, 비밀글, 19금 글은 뺀다(19금은 기본 가젯과 같은 규칙 — adult-board-contract). 추천이 같으면 최신 글 먼저.
- **자동 채우기 끄기**: 게시판별 설정 하나(기본 켬) — 버그 신고·기능 요청·공지처럼 카드가 어울리지 않는 게시판용. 관리자 하이라이트 게시판 곳 화면에서 바꾼다(게시판 상세 화면은 건드리지 않음 — 다른 작업과 파일이 겹침).
- **권한·감사**: 하이라이트와 같다(`highlight.read`·`highlight.manage`, 기존 감사 행위). 자동 채우기 스위치 변경도 감사에 남긴다.
- **성능**: API 서버 2~3대 전제. 게시판 목록을 열 때마다 무거운 집계를 하지 않게 짧은 캐시(기존 캐시 방식·캐시 관리 화면 규칙)를 쓰고, 하이라이트 저장·스위치 변경 때 그 게시판 캐시를 비운다. 추천 수가 조금 늦게 반영되는 것은 괜찮다.

## API (서버 구현 2026-11-26 — 확정)
- **공개** `GET /api/boards/{slug}/recommended`(로그인 없이, `no-store`) → `{ items: [{ postId, title, label, kind: "PICKED"|"AUTO", likeCount, prefix }] }` 최대 3, 고른 글 → 자동 채움 차례.
  - `title`: 고른 글 = 하이라이트 노출 제목(없으면 글 제목), 자동 = 글 제목. `label`: 고른 글의 하이라이트 요약을 한 줄로(줄바꿈·연속 공백 → 한 칸, 비면 null), 자동 = 늘 null — 「운영자 추천」·「추천 n · 말머리」는 화면이 i18n 으로 만든다. `prefix` = 말머리 이름 또는 null(고른 글에도 온다). `likeCount` = 캐시 시각 기준.
  - 게시판 판정은 글 목록과 같다: 없음·소모임 게시판 404 `BOARD_NOT_FOUND`, 꺼짐 403 `BOARD_INACTIVE`, 성인 전용 게시판 숨김 404·핀 필요 403 `ADULT_BOARD_PIN_REQUIRED`. 일반 게시판이 아니면(핫딜·홍보) `items: []`.
  - 고른 글은 그 게시판의 글이고 지금 보이는 것만(노출 켬·기간 안 · 지움/숨김/비밀글/19금 아님). 공지(고정) 글은 고른 글이면 둔다(자동 채움에서만 뺀다).
- **관리자**(`highlight.read`·`highlight.manage`, 모두 `no-store`):
  - `GET /api/admin/highlights/places` — 줄 `{ key, name, kind, total, boardId, autoFill }`, `kind` 에 `BOARD` 추가(고른 글이 있거나 자동 채우기를 끈 일반 게시판만, 게시판 차례, 홈·팁·가젯 페이지 뒤). `boardId`·`autoFill` 은 게시판 곳만(그 밖은 null). 이름은 게시판 사본에서 그때 읽는다(이름 변경 바로 반영, 영어 요청이면 영문 이름).
  - `GET /api/admin/highlights/boards` — 「+ 게시판 곳 추가」용 일반 게시판 전체(꺼진 것 포함) `[{ place, boardId, slug, name, active, autoFill, total, shown: 3 }]`.
  - `GET /api/admin/highlights?place=board-{id}` — 기존 응답 + `board`(위와 같은 모양, 게시판 곳이 아니면 null).
  - `PUT /api/admin/highlights/places/{place}/auto-fill` 본문 `{ autoFill: boolean }` → 위 `board` 모양. 게시판 곳이 아니면(모양·없는 게시판·일반 아님) 400 `VALIDATION fields.place`, 값 없으면 `fields.autoFill`. 바뀌었을 때만 감사 `HIGHLIGHT_AUTO_FILL`(대상 BOARD, place·from·to).
  - 기존 글 찾기·후보·만들기에 `place=board-{id}` 를 그대로 쓴다. 게시판 곳은 **그 게시판 글만** — 글 찾기·후보는 그 게시판으로 좁히고, 만들 때 다른 게시판 글이면 400 `HIGHLIGHT_POST_INVALID`(`fields.postId` 까닭 `OTHER_BOARD`). 곳 키는 있는 일반 게시판이어야 한다(아니면 `fields.place`).
  - 가젯 페이지 키가 `board-` 로 시작하면 400 `fields.key`(`gadgetPage.key.reserved`, 이미 그 키인 페이지를 고칠 때는 그대로 둔다).
- **저장**: shared `V273__highlight_board_settings`(게시판마다 한 행 `auto_fill` — 행이 없으면 켬, 게시판을 지우면 함께 지움). 게시판 곳 하이라이트는 `highlights.place = 'board-{id}'`(새 칸 없음).
- **캐시**: 새 캐시 `boards.recommended`(공개 화면, 기본 60초, 공용 — 항목 키 = 게시판 ID, 캐시 관리 화면에 나옴). 하이라이트 저장·자동 채우기 스위치(`HIGHLIGHT_SAVE`)·글 숨김/삭제(`POST_MODERATION`)·게시판 저장(`BOARD_SAVE`) 때 세대 번호로 모든 서버가 비운다(게시판 하나만이 아니라 캐시 전체 — 기존 캐시 방식). 새 추천 수는 TTL 만큼 늦게 반영.

## 미확정
- 카드 색(게시판 색 계열 vs 고정 초록) — 화면 확인 때 사용자 결정.
- 지운 게시판 곳의 하이라이트 줄은 지우지 않는다(공개는 404, 관리자 곳 목록에서는 안 보임) — 게시판 삭제(`BoardService`)는 다른 작업과 겹쳐 건드리지 않았다.
- 차단한 작성자의 글도 카드에 그대로 나온다(카드는 공용 캐시 — 게시판 목록은 「차단」 표시로 남기는 것과 다름). 필요하면 덧입힘 추가.
