# 19금 게시판 접근 설정·핀번호 — 계약

## 의도
성인 계정이어도 가족(아이)과 기기·계정을 같이 쓸 수 있어, 성인 전용 게시판은 회원이 직접 「접근」을 켜고 6자리 핀번호를 넣어야만 보이게 한다(사용자 2026-11-18). `adult-board-contract.md`(성인 전용 게시판 `adultOnly`)의 접근 판정에 한 겹을 더한다.

## 정책(사용자 확정 2026-11-18)
- **접근 설정**: 회원마다 「19금 게시판 접근」, 기본 꺼짐. 꺼져 있으면 본인인증 성인이어도 성인 전용 게시판은 지금의 「성인 아님」과 똑같이 다룬다 — 메뉴에서 빠지고, 게시판·글·검색·글쓰기·댓글이 404 처럼 「없는 게시판」, 19금 전용 가젯 없음.
- **켜기**: 계정 비밀번호 확인 + 핀번호 숫자 6자리(두 번 입력). 핀 없이 켜진 상태는 없다.
- **핀 확인**: 켜져 있어도 성인 전용 게시판에 들어가려면 핀번호를 맞게 넣어야 한다. 확인은 **1시간** 유지, 기준은 회원이 고른다.
  - `IDLE`(기본) — 마지막으로 성인 전용 게시판을 본 뒤 1시간이 지나면 다시 묻는다(보는 동안 연장).
  - `FIXED` — 핀번호를 넣은 뒤 1시간이 지나면 보는 중이어도 다시 묻는다.
- **틀림 잠금**: 연속 5번 틀리면 10분 동안 핀 입력을 막는다(회원 단위 — 기기를 바꿔도 잠김). 맞게 넣으면 틀린 횟수는 0.
- **본인 확인**: 접근 켜기 · 핀번호 바꾸기 · 핀번호 잊었을 때 다시 정하기 모두 계정 비밀번호. 끄기는 확인 없이(더 안전한 쪽).
- **범위**: 성인 전용 게시판(`boards.adult_only`)과 그 게시판을 보이는 19금 전용 가젯만. 일반 게시판 안의 19금 글(영상·짤의 「성인 전용」 말머리 등)은 지금처럼 본인인증 성인이면 보인다. 관리자 게시판 편집에는 새 옵션이 없다.

## 아이로빗 판단(사용자 반대 없으면 이대로)
- 핀 확인은 **기기(로그인)마다** 따로 — PC 에서 풀어도 휴대폰은 다시 묻는다. 로그아웃하면 풀린다.
- 켜져 있고 핀을 아직 안 넣은 상태: **메뉴에는 게시판이 보이고**, 들어가면 게시판 자리에 핀 입력 화면. 19금 전용 가젯은 핀을 넣기 전에는 숨김.
- 「지금 잠그기」: 이 기기의 핀 확인을 바로 없앤다.
- 계정 비밀번호가 없는 회원(소셜 로그인만)은 탈퇴와 같은 「최근 10분 안에 로그인」으로 대신한다(지났으면 다시 로그인 안내).
- 접근을 켜거나 핀번호를 새로 정한 직후 그 기기는 **열림**으로 둔다(방금 비밀번호와 핀을 넣었으므로). 다른 기기는 잠김.
- 핀번호는 해시로만 저장(계정 비밀번호와 같은 방식), 응답·로그·감사 기록에 싣지 않는다. `000000`·`123456` 같은 값도 막지 않는다(틀림 잠금이 막는다).
- 이미 성인 전용 게시판을 보던 회원도 배포 뒤 모두 꺼짐으로 시작한다.
- 성인 전용 게시판의 글이 알림·내 글 목록 등에 제목으로 나오는 곳은 이번에 거르지 않는다(`adult-content-contract.md` 미확정과 같음).

## 화면(user-web)
- **설정 › 19금 게시판** `/settings/adult-board` — 설정 메뉴에 본인인증 성인에게만 보인다(성인이 아니면 메뉴에 없고 주소로 오면 본인인증 안내).
  - 꺼짐: 스위치 한 줄 + 안내.
  - 켜짐: 스위치 · 핀번호(정한 날, [핀번호 바꾸기]) · 핀번호 다시 묻기(두 가지 중 하나) · 지금 잠그기(열려 있으면 남은 시간).
  - 켜기·바꾸기·다시 정하기 대화상자: 계정 비밀번호 · 핀번호 6칸 · 한 번 더.
- **핀 입력 화면** — 성인 전용 게시판 목록 `/boards/{slug}`·글 `/posts/{id}`·글쓰기에서 서버가 「핀 필요」라고 하면 내용 자리에 나온다: 6칸 입력(다 채우면 바로 확인), 틀리면 「n번 더 틀리면 10분 동안 잠겨요」, 잠기면 남은 시간, [핀번호를 잊었어요] → 설정 화면의 다시 정하기. 맞으면 보던 화면을 다시 읽는다.

## API 후보
| API | 내용 |
| --- | --- |
| `GET /api/me/adult-board` | `{ enabled, pinSetAt, relockMode: IDLE\|FIXED, unlocked, unlockedUntil, lockedUntil, passwordAvailable }` |
| `PUT /api/me/adult-board` | 켜기 `{ enabled: true, password, pin }` · 끄기 `{ enabled: false }` |
| `PUT /api/me/adult-board/pin` | 바꾸기·다시 정하기 `{ password, pin }` — 틀린 횟수·잠금도 푼다 |
| `PUT /api/me/adult-board/relock-mode` | `{ relockMode }` |
| `POST /api/me/adult-board/unlock` | `{ pin }` → 맞으면 이 기기 1시간 · 틀리면 `400`/`423` + `attemptsLeft`·`lockedUntil` |
| `POST /api/me/adult-board/lock` | 이 기기 지금 잠그기 |
| 성인 전용 게시판을 여는 API | 접근 꺼짐 → 지금의 「없는 게시판」 404 · 켜짐+핀 미확인 → `403 ADULT_BOARD_PIN_REQUIRED`(+ `lockedUntil`) |

## 화면 연결 메모(2026-11-18)
- 오류: `401 CURRENT_PASSWORD_WRONG`(비밀번호 칸 아래) · `429 LOGIN_LOCKED`(남은 시간 + 잠금) · `401 REAUTH_REQUIRED`(비밀번호 없는 회원 — 다시 로그인 안내) · `403 IDENTITY_REQUIRED`/`IDENTITY_UNDERAGE` · `409 ADULT_BOARD_DISABLED` · `400 ADULT_BOARD_PIN_WRONG`(+`attemptsLeft`) · `423 ADULT_BOARD_PIN_LOCKED`(+`lockedUntil`).
- 「핀 필요」는 성인 전용 게시판을 여는 **어느 API 든** 낸다(레이아웃·태그·댓글·투표·추천·신고·토론 포함). 화면은 `useApiClient` 한 곳에서 알림을 올리고(`useAdultBoardPinDemand`), 처음 읽을 때는 내용 자리에 핀 입력, 보던 도중(글 보기·글쓰기)에는 대화상자로 묻는다(쓰던 댓글·글 유지). 게시판 목록은 보던 도중에도 내용 자리를 핀 입력으로 바꾼다.
- 메뉴·게시판 목록은 켜기·끄기 뒤에 다시 받는다(서버가 핀 확인은 보지 않으므로 풀기·잠그기 때는 받지 않는다). 19금 전용 가젯은 홈·가젯 페이지·게시판 레이아웃에 들어올 때마다 새로 받는다.

## 서버 구현 메모(조사 2026-11-18)
- 핀 확인 상태는 **로그인 세션 속성**(Spring Session JDBC — 서버 여러 대가 같이 봄, 로그아웃·재로그인 때 저절로 풀림). 선례 `SecretPostUnlocks`.
- 접근 설정·핀 해시·틀린 횟수·잠금은 회원 단위 DB 표(선례 `member_view_settings`, 잠금 `LoginAttemptService`). 해시는 기존 `PasswordEncoder`, 비밀번호 확인은 `CurrentPasswordVerifier`.
- 판정은 성인 전용 게시판 자리(`PublicBoardService#requireAdultAccess` 등)만 `숨김/핀 필요/열림` 셋으로 바꾸고, 일반 19금 글 판정 `AdultContentGate` 는 그대로. 메뉴는 「성인 + 접근 켜짐」(핀은 안 봄), 가젯·게시판·글은 열림이어야 한다. 메뉴 캐시는 보는 사람과 무관한 재료라 그대로.
