# 성인 게시판(전방/후방)·19금 노출 — 계약

## 의도
본인인증한 성인만 들어가고 메뉴도 성인에게만 보이는 게시판 「전방/후방」을 커뮤니티에 둔다. 19금 글은 성인이어도 그 게시판 안과 19금 전용 가젯에서만 보인다(사용자 2026-11-16). 기존 `adult-content-contract.md`(말머리 「성인 전용」·19금 글 숨김)를 넓힌다.

## 게시판 옵션 `adultOnly`(성인 전용 게시판)
- `boards.adult_only boolean NOT NULL DEFAULT false`. 켜면 그 게시판 글은 모두 19금으로 저장(글쓴이 체크·말머리와 상관없이), `allowAdult` 도 켠 것으로 본다.
- **접근**: 본인인증한 성인(기존 `adultGate.adult(viewerId)` 와 같은 판정)이 아니면 게시판 정보·목록·글 상세·게시판 안 검색·글쓰기·댓글이 모두 막힌다 — 비회원·미인증 회원 모두 **404 처럼 「없는 게시판」**(존재를 드러내지 않음). 상세 아래 목록·이전/다음 글도 같은 판정.
- **메뉴**: 사이트 메뉴(PC 메뉴·모바일 메뉴 서랍·하단 탭·메뉴 바로가기·게시판 고르기 목록 등 공개 게시판 목록이 나오는 곳 전부)에서 성인이 아니면 그 게시판 항목이 빠진다. 메뉴 응답을 캐시하면 「성인용/일반용」 두 벌로 나누거나 화면이 성인 여부로 거른다(서버가 원천 — 화면 거르기만으로 끝내지 않는다).
- 관리자 게시판 편집 기본 정보에 「성인 전용 게시판(본인인증 성인만)」 스위치.

## 19금 노출 규칙(정정 — 성인이어도 숨김)
19금 글(`adult`)은 **성인이어도** 다음에서 빠진다: 홈·가젯 페이지·게시판 레이아웃의 모든 기본 글 목록 가젯(최신글·인기글·게시판 카드·하이라이트·새소식 등), `/popular`, `/latest`, 통합 검색, 공개 프로필 작성글·작성 댓글·수치, 글 상세 아래 [인기글]·[최신글] 탭.
보이는 곳: 그 게시판 안(목록·상세·게시판 안 검색 — 성인만), **19금 전용 가젯**(아래).
- 영상·짤처럼 19금 허용 게시판 안의 19금 글(말머리 「성인 전용」)은 지금처럼 그 게시판 안에서 성인에게만.

## 19금 전용 가젯
- 새 가젯 종류(예: `ADULT_POSTS`) 또는 기존 글 목록 가젯의 「19금 게시판 전용」 설정 — 고른 성인 전용 게시판의 글을 **목록형**으로. 성인에게만 그려지고(서버가 성인 아니면 빈 값·가젯 자체를 숨김), 성인이 아니면 자리도 없다.
- 커뮤니티 가젯 페이지 「영상·짤」 가젯 바로 아래에 이 가젯을 둔다(로컬 DB·설치 프리셋·데모 팩).

## 데이터(로컬 DB·설치 프리셋)
- 게시판 「전방/후방」(slug `adult` 같은 비직접적 slug — 예: `frontback`), 커뮤니티 메뉴 아래, `adultOnly=true`, 말머리 **짤·움짤·영상·썰·정보·잡담**.
- 안내문: 불법 촬영물·미성년자·실존 인물 합성(딥페이크)·성매매 홍보 금지, 어기면 영구 정지·신고.
- 영상·짤(`video`)의 말머리 「전방·후방」 글은 새 게시판으로 옮기고 말머리 「짤」, 영상·짤의 「전방·후방」 말머리는 없앤다(로컬 DB 는 이번에, 운영은 관리자 작업 또는 스크립트).

## 미확정
- 메뉴 캐시 방식(두 벌 vs 화면 거르기)은 구현 세션이 기존 캐시 구조를 보고 정한다.
