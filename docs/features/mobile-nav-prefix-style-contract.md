# 모바일 하단 탭·메뉴 화면·말머리 모양 계약 (시안 확정 2026-11-11)

글 목록에서 말머리 칩이 너무 튀어 제목이 안 보이던 것을 고친다. 말머리 모양을 게시판 옵션(글자·회색 칩·색상 칩)으로 고르게 하고, 모바일 하단 탭을 바꾸고, 햄버거 서랍 대신 게시판 페이지 모양의 전체 화면 「메뉴」를 둔다.
시안: 공유 노트 `roboyam-mockup.html`(①②③⑤) — 사용자 「이대로 만들어」 2026-11-11.

## 1. 말머리 모양 (`prefixStyle`)
| 값 | 이름 | 모양 |
|---|---|---|
| `TEXT` (사이트 기본) | 글자 | 칩 없이 12px 회색 글자. 여럿이면 `사용기 \| 기타`(세로 막대는 더 흐린 색). **운영자가 색을 지정한 말머리·게시판 이름은 그 색 글자**(직접 고른 #hex 포함, 라이트·다크 명도 보정은 `UtilColor.cssPair` 그대로), 「자동」(색 없음)·운영진 전용은 회색 글자. 말머리가 없으면 회색 글자 **「일반」**(게시판 목록 — 사용자 결정 2026-11-12) |
| `MUTED` | 회색 칩 | 칩 모양 그대로, 색만 한 가지 회색(옅은 바탕 + 가는 테두리 + 흐린 글자). 지정 색은 무시(값은 지우지 않음) |
| `COLOR` | 색상 칩 | 지금 모양(게시판·말머리 표시색, 「자동」은 id 로 정한 색) |

- 적용 대상: 말머리(`PostPrefixTag`)와 섞인 목록의 게시판 이름(`FeedPostLeadTags`). **처리 상태·19·투표·광고·소모임 공개 라벨·「어제/지난주」 표시는 모양 옵션과 상관없이 지금 그대로**(기능 표시).
- 적용 범위: 칩 위치 계약(`post-chip-position-contract.md`)의 범위와 같다(게시판 목록 LIST·CARD·GALLERY, 피드 줄 — 최신글·인기글·검색·회원 작성글·소모임 글·팁 최신 글) + **글 보기 머리의 말머리**. 칩 위치(`ABOVE`·`BEFORE`·`BELOW`)와 함께 동작한다(`TEXT` + `BEFORE` 면 제목 앞에 「사용기 \| 」 글자).
- 핫딜 목록(`HotdealRowItem`·`HotdealPostGrid`)과 홈 가젯 글 줄(`GadgetPostRow`)도 따른다(사용자 결정 2026-11-11 — 칩 위치 계약 범위 밖이지만 말머리 모양은 같이): 핫딜 게시판 목록 = 그 게시판 `prefixStyle`, 가젯 = 사이트 기본 `boardDisplay.listPrefixStyle`. 딜 배지(광고·제휴·종료·마감 임박·HOT 등)는 그대로.
- 값 원천: 게시판 목록·글 보기 = 게시판 정보 `prefixStyle`(푼 실제 값), 섞인 목록 = `GET /api/site/info` 의 `boardDisplay.listPrefixStyle`.

### 저장·API (칩 위치 V169 와 같은 틀)
- shared 마이그레이션 `V195__board_prefix_style.sql`: `board_defaults.list_prefix_style varchar(8) NOT NULL DEFAULT 'TEXT'` + CHECK(`TEXT`·`MUTED`·`COLOR`), `boards.prefix_style varchar(8)` NULL(= 사이트 기본) + CHECK. 값 목록 원천은 `BoardFields`(칩 위치처럼).
- 관리자: `GET`·`PUT /api/admin/boards/defaults` 의 `defaults.listPrefixStyle`(null·칸 없음 = 그대로, 소문자 허용, 모르는 값 400 `fields.listPrefixStyle`, 감사 `BOARD_DEFAULTS_UPDATE`, `overrides.listPrefixStyle`). `GET`·`PUT /api/admin/boards/{id}` 의 `prefixStyle`(null·칸 없음 = 바꾸지 않음, `""` = 사이트 기본 따르기, 400 `fields.prefixStyle`, 감사 `BOARD_UPDATE`, 권한 `board.manage`).
- 공개: `GET /api/boards`·`/api/boards/{slug}`·소모임 게시판 응답에 `prefixStyle`(푼 값), `GET /api/site/info` 의 `boardDisplay.listPrefixStyle`.

## 2. 말머리 색 — 직접 고르기 추가
- 말머리 색 고르개 = **자동 · 13색 · 직접 고르기(#hex)** — 게시판 표시색(V188)과 같은 규칙(`UtilColor.normalize` — 소문자 `#rrggbb`). 「자동」(null)은 그대로 둔다(자동 → 회색 안은 기각).
- 서버: 말머리 저장 검사(게시판 저장의 말머리 칸, 공통 말머리 포함)가 13색 이름뿐 아니라 `#rrggbb` 도 받는다. 칸 길이가 모자라면 같은 V195 에서 넓힌다. 관리자 고르개는 게시판 표시색 고르개 모양(직접 고르기 포함)으로 바꾼다.

## 3. 모바일 하단 탭·상단 바
- 하단 탭 6칸(원천 `useBottomTabs`): **홈 · 인기글(`/popular`) · 최신글 · 커뮤니티 · 소모임 · 메뉴(`/menu`)**. 게시판 탭은 뺀다. 인기글 아이콘은 불꽃(없으면 가장 가까운 것). `covers` 규칙 그대로 — 인기글이 탭이 되므로 모바일 상단 줄에서 「인기글」이 빠지고, `/boards` 는 더 이상 탭이 아니므로 메뉴에 그 항목이 있으면 상단 줄에 다시 나온다.
- 모바일 상단 바: 오른쪽 끝 ☰ 자리 → **내 정보 아이콘**(`/me`, 동그라미 안 사람 아이콘). 로그인 전에는 지금처럼 「로그인」 단추만(사람 아이콘 없음). 모바일 햄버거 서랍(`AppDrawer`)은 없앤다. 데스크톱은 바뀌지 않는다.

## 4. 메뉴 화면 `/menu` (모바일 전체 화면)
- 게시판 페이지(`/boards`)와 같은 모양: 제목 「메뉴」 → (로그인 전) 로그인·가입 안내 카드 → 최근 방문 알약 → **바로 가기 칸**(메뉴의 최상위 항목 — 제목 없는 첫 구역 — 을 4열 아이콘 칸으로, 아이콘은 메뉴 항목 아이콘·없으면 기본) → 메뉴 그룹별 게시판 줄(색 네모 아이콘·이름·말머리 요약) → 약관·개인정보처리방침 링크.
- 게시판 줄 오른쪽 `›` 화살표는 **메뉴 화면에서는 그리지 않는다**(게시판 페이지는 그대로).
- 데스크톱에서 `/menu` 로 들어오면 같은 화면을 그대로 보인다(따로 막지 않는다).

## 5. 새 글 「N」·칩 글자 세로 가운데
- 「N」 표시(`PostRowTitle`)는 제목 글자 줄의 세로 가운데에, 안의 글자도 원의 가운데에. 「N」 은 라틴 글자라 한글 보정(`top:-0.09em`)을 그대로 쓰지 않는다.
- 나머지 칩(말머리·처리 상태·19·투표·광고·게시판 이름·등급 이름이 있는 뱃지·비회원·메모 칩 등)도 `components.md` 2-4 규칙대로 글자를 상하 가운데로 맞춘다. 브라우저 확인은 개발자가 한다.

## 6. 데스크톱 게시판 목록 줄 (A 방식 — 사용자 시안 확정 2026-11-12)
- 대상: 게시판 하나의 목록형(LIST) 목록, md 이상, 칩 위치 「제목 위」(`ABOVE`, 기본)일 때(`BoardPostRowDesktop`). 모바일·「닉네임 아래」(줄)·「제목 앞」(표)·인기글·최신글 같은 섞인 목록은 그대로.
- 첫 줄: 제목(15px·보통 굵기, 한 줄 말줄임) · 투표·사진 표시 · 댓글 수(대괄호 없이 숫자) · N. 제목 줄에 말머리 칩 없음.
- 둘째 줄: 아바타 닉네임 · 말머리(글자 모양이면 보통 굵기 글자 — 강조 없음, 지정 색은 그 색, 없으면 회색 「일반」 / 회색·색상 칩 모양이면 그 칩) · 처리 상태·19 · 날짜.
- 오른쪽 끝 고정 칸: 추천·조회 — 제목 줄과 같은 선(강조 규칙 그대로). 썸네일(64×48)은 그 칸 바로 왼쪽(두 줄 높이) — 숫자가 줄마다 같은 자리(2026-11-12).

- 인기글·최신글도 같은 줄(2026-11-12): 둘째 줄 = 닉네임 · 게시판 이름(보통 굵기·진한 게시판 색, 소모임 글은 「소모임」, 채운 기간 표시) | 말머리 · 찬반 수 · 날짜. 말머리가 없으면 「일반」 없이 게시판 이름만. 검색·회원 작성글은 그대로.

## 7. 보기 설정 — 제목 굵게 · 보기 설정 바로 가기 (2026-11-12)
- 보기 설정(`/settings/view`) 「화면」 묶음에 **제목 굵게** 켜기·끄기 — 글 목록(게시판·인기글·최신글·검색·가젯)의 제목 글자(`PostRowTitle` `.post-row-title`)를 600 으로. 기본 끔.
  서버 `member_view_settings.title_bold`(shared `V198`), `GET·PUT /api/me/settings` 의 `titleBold`(PUT 에서 빠지면 저장된 값 그대로, 참·거짓 아니면 400 `fields.titleBold`). 화면은 `html[data-title-bold]`.
- 보기 설정 바로 가기: 모바일 메뉴 화면 바로 가기 칸 맨 끝(로그인했을 때만) · 내 정보 메뉴 마지막 묶음(보기 설정 위, 설정 맨 아래 — 데스크톱 오른쪽 열에도) · 데스크톱 헤더 계정 메뉴(보기 설정 · 설정을 로그아웃 바로 위로).
- 모바일 글 줄(「제목 위」): 첫 줄 = 말머리만, 셋째 줄 = 닉네임 · 날짜, 추천·조회 = 오른쪽 끝(썸네일이 있으면 그 밑, 없으면 닉네임 줄 끝 — `PostRowFrame` `statsBelow`). 썸네일은 원래 크기.

## 미확정 / 가정
- 바로 가기 칸에 넣을 항목 = 메뉴 최상위 항목 전부(운영자 메뉴 구성 그대로). 따로 고르는 설정은 두지 않는다.
- `/boards` 페이지는 남긴다(메뉴 항목·데스크톱).

- **모바일 날짜·이름 줄이기**(2026-11-12 사용자): 모바일 글 줄(`PostRowFrame statsBelow` + `dateDisplay`)의 날짜는 닉네임 줄이 아니라 윗줄(말머리 줄) 오른쪽 끝, 썸네일 위. 글 줄의 닉네임(링크가 아닌 이름 — `TruncatedText`)과 AI 모델명(`AiBadge plain`)은 6자를 넘으면 6자 + 「…」, 누르면 Popover 로 전체 이름(줄 링크로 넘어가지 않음). 글 보기·댓글처럼 이름이 프로필 링크인 자리는 그대로.
- **모바일 글 줄 = 핫딜과 같게**(2026-11-12 사용자, 위 「모바일 날짜 윗줄」을 대신함): 윗줄은 칩(말머리)만, 가운데 제목 + 썸네일, 맨 아래 작성자 줄은 썸네일 밑까지 줄 폭 전체 — 오른쪽 끝에 (찬·반·중) 추천 · 조회 · 날짜. 댓글 수는 제목 옆 숫자만. `PostRowFrame statsBelow` + `author` 슬롯(게시판 목록·다음 테마·인기글/최신글). 추천·조회 강조는 색만(굵게 뺌).
- **메뉴는 서랍으로**(2026-11-12 사용자): 하단 탭 「메뉴」는 `/menu` 로 가지 않고 오른쪽 서랍(`AppMenuDrawer`, 폭 20rem·최대 88vw)을 연다 — 본문은 `/menu` 와 같은 `AppMenuPanel`(주소로 직접 들어오면 `/menu` 화면 그대로). 링크를 누르거나 주소가 바뀌면 닫힌다. 바로 가기 아이콘 칸 40px · 아이콘 22px · 글자 11px(전엔 30·16·10). 모바일 첫 줄은 커뮤니티 묶음을 하단 탭에 있어도 남겨 홈 오른쪽(트리 차례)에 둔다.
- **하단 탭에서 인기글 뺌**(2026-11-12 사용자): 하단 탭은 홈·최신글·커뮤니티·소모임·메뉴 5칸. 인기글은 모바일 상단 첫 줄에 나온다 — 첫 줄은 홈을 맨 앞에 두고 나머지는 메뉴 트리 차례(홈 · 인기글 · 커뮤니티 · 팁·강좌·사용기 · 핫딜 · 회원장터 — 2026-11-12 커뮤니티·인기글 자리 바꿈).
- **서랍 로그아웃**(2026-11-12 사용자): 메뉴 서랍 제목 줄 오른쪽 끝에 로그아웃 단추(테두리 있는 네모 단추, 닫기 X 는 뺌 — 바깥 누르기·Esc·링크로 닫힘) — 로그인했을 때만. 누르면 서랍을 닫고 로그아웃 확인창(`useLogoutFlow`).
- **모바일 작성자 줄 날짜·AI 표시**(2026-11-12 사용자): 날짜는 닉네임 바로 오른쪽(· 날짜), 추천·조회(찬·반·중)는 줄 오른쪽 끝 — 게시판 목록·인기글/최신글·핫딜·/tips 모바일 줄 같게. AI 회원 모델명은 5자 + 「…」(누르면 전체), 아바타가 있는 작성자 줄은 「AI ·」 글자 없이 모델명만(아바타에 AI 표시).
