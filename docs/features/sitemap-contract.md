# 사이트맵 계약 (sitemap)

구글 같은 검색엔진이 비회원이 읽을 수 있는 글을 빠짐없이 찾게 한다(애드센스 심사 준비, 사용자 결정 2026-11-23 — 1단계만).
관리자 화면·설정·DB 변경은 없다. 첫 HTML 에 글 본문을 싣는 것(2단계)은 색인 상태를 보고 따로 정한다.

## 주소(api 서버)
| 주소 | 응답 |
|---|---|
| `GET /sitemap.xml` | 사이트맵 색인 — `/sitemap-pages.xml` 과 `/sitemap-posts-{n}.xml`(1부터, 공개 글이 있는 만큼) |
| `GET /sitemap-pages.xml` | 고정 화면(`/`, `/about`, `/terms`, `/privacy`, `/policy`)과 공개 게시판 목록 `/boards/{slug}` |
| `GET /sitemap-posts-{n}.xml` | 공개 글 `/posts/{id}` — 글 ID 오름차순 10,000개씩, `lastmod` = 고친 시각(없으면 쓴 시각) |
| `GET /robots.txt` | 모두 허용 + `Sitemap: {공개 주소}/sitemap.xml`. `/api/` 를 막지 않는다(구글이 화면을 그릴 때 부른다) |

- 주소의 앞부분은 사이트 설정의 공개 주소(`publicUrl`)다. 설치 전이거나 공개 주소가 없으면 사이트맵은 본문 없는 404, `robots.txt` 는 `Sitemap` 줄 없이 내린다.
- 없는 번호(`n` 이 0 이하이거나 범위 밖)는 404 다. `application/xml`·`text/plain` 이고 `ApiResponse` 로 감싸지 않는다.
- 캐시 틀(cache-admin)에 넣지 않는다. 요청마다 읽고 `Cache-Control: public, max-age=3600`(사이트맵만)으로 되묻기를 줄인다.

## 사이트맵에 넣는 것 · 빼는 것
- 게시판: 공개 게시판(켜짐, 소모임 게시판 아님) 중 성인 전용이 아니고 유효 정책 「검색엔진 색인」이 켜진 것.
- 글: 비회원이 글 보기로 열 수 있는 글만 — 공유 미리보기(`PostLinkPreviewService`)와 같은 판정이다.
  - 빼는 것: 지운 글·예약 삭제 시각이 지난 글·임시저장, 숨긴 글(임시조치는 기간 안일 때), 비밀글, 19금 글, 꺼진 게시판·성인 전용 게시판·색인을 끈 게시판의 글.
  - 소모임 글은 열린(ACTIVE) 소모임의 공개 글이고 작성자가 나가서 가린 글이 아닐 때만 넣는다. 소모임 게시판은 꺼져 있어도 글이 열리므로(`PostOpenRules`) 켜짐을 보지 않고 색인 정책만 본다.
- 로그인·가입·설정·내 정보·관리·글쓰기 화면은 넣지 않는다.

## 없는 글은 404
- `/posts/{id}` 화면 요청에서 글이 없거나 `isGoneAt` 이면 **화면(index.html)은 그대로, 상태만 404** 로 내린다(`ETag`·304 없이).
- 숨긴 글·비밀글·19금 글·성인 게시판 글·소모임 비공개 글은 지금처럼 200 이다(볼 수 있는 회원이 있고, 있는지 없는지를 상태로 알리지 않는다).
- 관리자 미리보기·설치 전은 지금처럼 200. 글을 읽다 실패해도 200(화면을 막지 않는다).

## 대표 주소(canonical)
- 서버: 공유 미리보기를 채우는 글(비회원이 읽을 수 있는 글)의 첫 HTML 머리에 `<link rel="canonical" href="{공개 주소}/posts/{id}">`. 물음표 뒤는 붙이지 않는다.
- 화면: 글 보기에서 같은 링크를 관리해, 다른 화면으로 옮기면 사라지고 다른 글로 옮기면 바뀐다(휴대폰 공유가 이 주소를 쓰므로 옛 글 주소가 남으면 안 된다).

## 배포 뒤 확인
- Cloudflare 가 `robots.txt` 앞에 자기 내용을 붙이는 동안에도 `Sitemap` 줄이 남는지 확인한다.
- Google Search Console 에 `https://irobit.kr/sitemap.xml` 을 제출한다.
