# 에디터 이미지 도구 계약

글쓰기 에디터(`@irobit/rich-editor`, 고급 수준)에서 이미지를 고르면 도구 막대가 떠서 정렬·크기·캡션·대체 텍스트를 정한다. 기사·리뷰 글처럼 사진 배치를 손봐야 하는 글을 위한 기능이다.
2026-11-15 사용자가 시안을 「추천안대로 확정」했다.

## 화면

- 쓰는 곳: user-web 글쓰기·고치기(고급 에디터 게시판), admin-web 공지(고급), 공동구매 상품·공동구매 설명. 에디터가 같아서 함께 생긴다. 약관·사이트 소개·메일 양식은 이미지가 없어 해당 없음.
- 이미지를 누르면(노드 선택) 이미지 위에 도구 막대가 뜬다: 정렬 왼쪽·가운데·오른쪽 | 크기 25%·50%·75%·원본 | 캡션 | 대체 텍스트 | 지우기. 위쪽 서식 도구 모음은 그대로 둔다.
- 캡션: 이미지 아래 한 줄 칸. 서식 없는 글자 최대 200자. 캡션을 껐다 켰다 할 수 있다(빈 캡션은 저장하지 않는다).
- 대체 텍스트: 화면 읽기용(보이지 않음), 최대 200자. 도구 막대에서 연 동안만 칸이 보인다.
- 새로 넣는 이미지의 기본값은 가운데·원본이다. 예전 글의 이미지는 건드리지 않으면 지금처럼 왼쪽·원본으로 남는다.
- 글 보기에서는 크기를 본문 폭의 %로 보인다. 원본보다 크게 늘리지 않는다. 휴대폰(768px 미만)에서는 25%를 50%로, 50%·75%를 꽉 차게 보인다.
- 문구: `richEditor.imageTools.*`(ko·en).

## 저장 모양(서버 정화 허용)

```html
<figure data-align="left|center|right" data-width="25|50|75">
  <img data-image-id="123" alt="대체 텍스트">
  <figcaption>캡션 글자</figcaption>
</figure>
```

- 정렬·크기·캡션이 하나도 없으면 `figure` 없이 `<img data-image-id>` 하나만 저장한다(예전 모양과 같다). 「원본」은 `data-width` 가 없는 것이다.
- 서버 `RichText`(고급 수준): `figure`·`figcaption` 를 허용한다. 받는 값은 `data-align`(left·center·right)과 `data-width`(25·50·75)뿐이고, `img` 에는 `data-image-id` 와 `alt` 만 남긴다. `RichText.figures` 가 한 모양으로 맞춘다. 캡션은 태그를 떼고 공백을 줄인 글자 200자까지이고, 비면 뺀다. 이미지 하나를 감싼 모양이 아닌 `figure`·`figcaption` 은 태그만 벗기고 글자는 남긴다. 임의의 `style`·`class` 는 계속 버린다.
- 대체 텍스트는 정화기가 이스케이프한 값을 `PostImages` 가 서버 이미지 태그의 `alt` 에 그대로 넣는다(없으면 `alt=""`).
- 캡션 글자는 보이는 글자에 들어가므로 본문 길이·검색·금지어(가림 포함)에 똑같이 적용된다.
- 대체 텍스트는 보이는 글자(본문 길이·검색)에는 들어가지 않는다. 금지어 검사(`ContentBody.wordsHaystack`)와 가림(`RichText.maskAlts`)에는 들어간다(2026-11-15 후속).
- 공동구매 상품 설명(`GroupBuyDescriptionHtml`)도 같은 `figure` 규칙을 허용하고 `RichText.figures` 로 맞춘다(시험 `GroupBuyDescriptionFigureTest`).
  `img` 의 `data-image-id`(숫자)도 남긴다. 그래야 고치기 화면의 에디터가 저장된 이미지를 다시 읽는다(2026-11-15 후속).
  이 수정 전에 저장한 설명의 이미지에는 표식이 없다. 그래서 그 상품을 고칠 때는 이미지를 다시 넣어야 한다(운영 전이라 데이터를 고치지 않는다).
- 마이그레이션은 없다. 이미 저장된 본문은 바꾸지 않는다.

## 이번에 하지 않은 것

- 이미지에 링크 걸기: 광고 링크 악용 우려와 링크 수 규칙 때문에 뺐다.
- 글 감싸기(float): 휴대폰에서 모양이 깨져 뺐다.
- 모서리를 끌어 자유롭게 크기 바꾸기: 저장 값이 정해진 목록을 벗어나 뺐다.

## 미확정

- 없음. 처음에 미확정이던 두 가지(대체 텍스트 금지어 검사, 공동구매 설명의 이미지 표식)는 위 「저장 모양」에서 처리했다.
