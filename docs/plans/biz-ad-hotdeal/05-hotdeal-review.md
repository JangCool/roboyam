# 회원 핫딜 1차 — 사용성·정책 보강 검토 (2026-11-01)

다른 커뮤니티·핫딜 사이트 조사와 설정·정책 빈 곳 검토(둘 다 Fable)를 합쳐 정리했다. 화면 목업(브랜치 `claude/hotdeal-member-mockup-616fb9`)과 계약 `docs/features/hotdeal-contract.md` 가 바뀌어야 할 것만 적는다.
조사 근거: 퀘이사존·에펨코리아·루리웹·클리앙·쿨엔조이·딜바다·OzBargain 직접 확인, 뽐뿌·HotUKDeals·Slickdeals·mydealz 일부, 아카라이브 미확인(검색 요약).

## 2. 화면 개선 — 1차에 넣기
**목록**(`HotdealRowItem`·`HotdealBadges`·`HotdealPriceLine`·`HotdealPostGrid`, 가젯·카드·갤러리 공용)
1. 배송비 3상태: 0 → 「무료배송」, n → 「+n원」, 모름 → 「배송비 모름」(옅게, compact 는 생략 가능).
2. 배지: 재고 `SOLD_OUT` 「품절」·`LOW` 「얼마 안 남음」, 마감 48시간 안 「N시간 남음/내일 마감」, 추천 ≥ `hotLikeThreshold`(기본 10) 「HOT」, 링크 바뀜·가격 수정 N회(D3).
3. 메타 줄에 조회수.
4. 쇼핑몰 칩 필터(말머리 아래, 상위 8몰 + 전체, `?store=`).
**쓰기**(`HotdealDealFields`·`write.vue`)
5. 제목 안내: 「상품명만 적어요 · 쇼핑몰·가격은 아래 칸이 목록에 보여 줘요」, 제목이 `[` 로 시작하거나 `원)` 로 끝나면 「자동으로 붙어요 — 지울까요? [지우기]」(막지 않음).
6. 가격 도움말: 딜가 = 쿠폰 적용 뒤 실제 결제가(배송비 제외), 카드 한정 할인은 가격 기준에. **가격 기준을 선택지 + 메모로**: 표시가 `LISTED`·쿠폰가 `COUPON`·카드 할인가 `CARD`·회원가 `MEMBER`·해외 직구 `OVERSEAS`(+ 「관부가세 포함」 체크), 선택지는 배지로. 0원 딜은 가격 기준 필수, 할인율 ≥ `discountWarnPercent`(90) 면 경고 + 가격 기준 필수. 딜가·정상가·배송비 상한 `priceMaxWon`(1억). 마감 도움말 「비우면 30일 뒤 기간 종료로 바뀌어요」. `startsAt` 은 1차에서 뺀다.
7. 같은 딜 안내: 줄마다 「이 글보다 N원 저렴/비쌈」 + 「그 글 댓글로 가격 변동을 알려 주는 것도 좋아요」.
8. 하루 글 한도·같은 몰 간격에 걸리면 안내(`429 DEAL_DAILY_POST_LIMIT`·`DEAL_SAME_STORE_TOO_SOON` 목업 스위치).
**글 보기**(`HotdealDealCard`)
9. 같은 딜 묶음 가격 차.
10. 끝난 딜에 「이 상품 새 딜 올리기」 → `/write?board={slug}&from={postId}`(링크·몰·이미지·제목 미리 채움, 가격·마감 비움).
11. 작성자 종료 되돌리기(D2): 조건 맞을 때만 [다시 진행 중으로] + 남은 시간.
12. keep(「아직 진행 중이에요」)은 최대 `keepMaxCount`(2)번 — 넘으면 단추 대신 「운영자 확인 중」. keep 할 때 「가격·재고를 고쳐 주세요」 안내.
13. **제휴 표기(공정위 추천·보증 심사지침 2024-12 개정 — 조건부 표현 금지·첫 부분 표시)**: 목록 줄·카드 제목 앞 배지 「제휴·수수료」, 카드 첫 줄 고정 문구 「제휴 링크 — 이 링크로 구매하면 작성자가 판매자로부터 수수료를 받습니다」, 글쓴이 체크 문구도 단정형. 카드 아래 고지 「아이로빗은 판매자가 아니에요. 가격·재고는 판매처 기준이에요」.
14. 신고 창에서 「가격 허위」를 고르면 「품절·가격 변경 알리기로 접수돼요」 안내(D4).
**가젯**(`HomeGadgetHotDeals`)
15. 「핫딜 더 보기 →」 링크.
**관리자**
16. 핫딜 설정 칸 추가(아래 3절).
17. 링크 규칙: 선택 칸 `keyParams`(같은 딜 판정에 남길 쿼리, 예 `11st.co.kr → prdNo`), 규칙을 차단으로 바꿀 때 「진행 중 글 N건」 미리 보기.
18. 의심 후보: 판매처 후보 종류(`kind=STORE`) + 서랍에 [글 숨기기]·[회원 제재로 가기]·[이 몰 규칙 등록] 바로가기.
19. 글 서랍에 딜 칸 수정 이력 탭(D3).
20. 신고 사건 서랍 조치 사유에 핫딜 사유 2개 + [핫딜 종료] 조치.

2차로 미룸: 키워드 알림, 종료된 지난 딜가·유사 딜, 「아직 살 수 있어요」 상쇄 투표, 관계자 자기 신고 배지, 모바일 고정 구매 단추. 안 함: 비추천·온도, 정렬 추가, 이미지 필수, 외부 가격 크롤링, 글 작성 대량 포인트.

## 4. 고정 규칙 (계약에 적고 서버 단계에서 테스트로 막을 것)
1. **OG 가져오기 보안**: 기존 `OutboundTargetGuard`·`SafeHttpClient` 재사용, 사설망 늘 거절, 리디렉션 최대 3회·매 단계 재검사, `text/html` 만·1MB·`<head>` 까지, 연결 2s·읽기 4s·전체 6s, 전용 풀 동시 4, 회원 분당 10회, 캐시 24시간(실패 10분). 보안 값은 설정 화면에 두지 않는다.
2. **최종 URL 판정**: 리디렉션 체인의 모든 호스트에 링크 규칙 적용(차단 우선 > 제휴), 응답 `finalHost`. 제휴 네트워크 도메인(링크프라이스·애드픽·텐핑 등) 시드 추가, `coupa.ng` 는 차단이 아니라 제휴로(공식 단축 여부 확인 필요).
3. **같은 딜 키**: 스킴·호스트 소문자·www·기본 포트·조각·끝 `/` 제거 + 추적 파라미터 제거(`utm_*`·`fbclid`·`gclid`·`igshid`·`ref`·`tag`·`aff*`·`spm`·`_trkparms`·`sub_id`) + 규칙 `keyParams` 가 있으면 그 쿼리만 → 정렬 → SHA-256. 같은 딜 = 공개·진행 중(ACTIVE·FLAGGED)만.
4. 종료 요청 자격(1절), 중복 요청 409 는 한도를 쓰지 않음, 하루 = 한국 0시. 같은 작성자 기간 한도.
5. 보상: 의심 구간 요청자에게만, 종료 경로 셋 모두, 지급 하루 5회(포인트 정책).
6. 재고 `SOLD_OUT` 저장 = 작성자 종료. 탈퇴 작성자의 진행 중 딜 = 작성자 종료, 정지 회원의 딜은 그대로. 탈퇴 요청자의 요청 줄은 지우되 이미 의심이 된 상태는 유지.
7. 수정 저장 때 늘 현재 규칙으로 링크 재판정 — 차단이면 저장은 허용하고 경고(`warnings[]`) + 관리자 목록 「차단 도메인 진행 중」 거르기.
8. 집계(가젯·같은 딜·인기글)는 공개 글만, 인기글은 종료·기간 종료 제외(의심은 포함), 핫딜 게시판은 19금 끔 고정, 광고 숨김은 핫딜 가젯과 무관.
9. 알림: 회원 — 종료 요청 문턱·자동 종료·운영진 종료(사유)·자동 기간 종료 1회. 운영자 — 위장 홍보 후보(`HOTDEAL_SUSPECTED_PROMO` 예약 켬)·keep 한도 초과·링크 호스트 바뀜. 감사는 모두 일반(GENERAL) 분류.
10. 2차 맞물림: 사업자 글은 종료 요청 받음·위장 홍보 집계 제외·인기글 제외·수정 이력 같은 표, `deal_settings` 같은 행에 2차 칸.
