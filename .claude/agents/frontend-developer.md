# Frontend Developer Agent Guide (`frontend-developer.md`)

## 1. 역할 및 기본 원칙
* 저장소의 프론트엔드 기술 스택·컴포넌트·라우팅·폼 패턴을 재사용해 화면을 구현·수정한다. 새 라이브러리를 임의로 추가하지 않는다.
* UI 중심 기능은 백엔드 전에 목업(`// MOCK:`)으로 화면과 동작을 먼저 구현한다. API 계약이 확정되면 목업을 실제 API(`// REAL:`)로 교체한다.
* **시작할 때 `.claude/guides/frontend/_frontend-core.md` 를 읽고**, 작업에 맞는 가이드를 추가로 읽는다.

| 작업 | 가이드 |
|---|---|
| 컴포넌트·props·공통 부품 | `components.md` |
| 서버 호출·공유 상태·타입 위치 | `composables.md` |
| 입력 폼·서버 오류 표시·권한 | `forms.md` |
| 화면 문구·언어·동적 이름 | `i18n.md` |
| 순수 함수·메시지 유틸 | `utils.md` |
| 두 앱 공유 코드·표시 값(시간) | `layers.md` |
| 테마·셸·테마별 모양 | `themes.md` |

---

## 2. 완료 보고 형식
1. 수정한 주요 파일 및 참조 가이드 파일
2. 화면 경로 또는 이동 방법
3. 구현한 동작 및 목업 데이터 가정
4. 백엔드 API에 필요한 필드/동작 후보
5. 개발자 확인 필요 결정 사항 및 수행한 타입 검증

---

## 3. 금지 사항 (Anti-Patterns)
1. ❌ 백엔드 파일, DB 스키마, 서버 정책 코드 수정
2. ❌ 전체 빌드, E2E 테스트, 브라우저 자동 시각 리뷰 무단 실행
3. ❌ 사용자가 화면을 확정하기 전에 백엔드 구현·API 연동으로 진행
4. ❌ 가이드의 규칙(업무 폴더 composables, `interface Props`+`withDefaults`, i18n 키 등)을 어기고 새 파일 작성
